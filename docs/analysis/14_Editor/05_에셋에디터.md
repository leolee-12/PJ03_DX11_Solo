# [14-5] Editor — 에셋 에디터 패턴

> 분석 대상: UE4 4.27 `Source/Editor/` StaticMeshEditor, SkeletalMeshEditor, TextureEditor 모듈 + `Source/Developer/AssetTools/`
> 선행: [14-1] 구조파악 결과 참조

## 1. FAssetEditorToolkit을 상속하는 에셋 에디터의 공통 패턴

### 1.1 상속 구조 비교

```
FAssetEditorToolkit (IAssetEditorInstance + FBaseToolkit)
  │
  ├─ IStaticMeshEditor : FAssetEditorToolkit          ← 직접 상속
  │    └─ FStaticMeshEditor (+ FGCObject, FEditorUndoClient, FNotifyHook, FTickableEditorObject)
  │
  ├─ ITextureEditorToolkit : FAssetEditorToolkit       ← 직접 상속
  │    └─ FTextureEditorToolkit (+ FEditorUndoClient, FGCObject)
  │
  └─ FWorkflowCentricApplication : FAssetEditorToolkit ← 워크플로우 기반 확장
       └─ ISkeletalMeshEditor : FWorkflowCentricApplication + IHasPersonaToolkit
            └─ FSkeletalMeshEditor (+ FGCObject, FEditorUndoClient, FTickableEditorObject)
```

### 1.2 공통 구현 패턴 (모든 에셋 에디터가 따르는 규칙)

| 패턴 | 설명 | 3개 에디터 모두 적용 |
|------|------|---------------------|
| **FGCObject 상속** | UObject 참조를 AddReferencedObjects()로 GC 보호 | O |
| **FEditorUndoClient 상속** | PostUndo()/PostRedo()로 Undo 시 UI 갱신 | O |
| **RegisterTabSpawners/UnregisterTabSpawners** | 탭 등록/해제 (FAssetEditorToolkit 요구) | O |
| **GetToolkitFName/GetBaseToolkitName** | 에디터 식별자/표시명 반환 | O |
| **GetWorldCentricTabPrefix/ColorScale** | 월드-센트릭 모드 탭 접두사/색상 | O |
| **InitXxxEditor() 메서드** | 에셋을 받아 에디터 초기화 | O |
| **OnRequestClose() 오버라이드** | 에디터 닫기 전 정리 로직 | O |
| **UObject* 멤버로 편집 대상 보관** | StaticMesh*, SkeletalMesh*, Texture* | O |

### 1.3 초기화 흐름 (공통)

```
[AssetTypeActions] OpenAssetEditor(Objects)
  │  ← 콘텐츠 브라우저 더블클릭 또는 OpenEditorForAsset() 호출
  ▼
[EditorModule] CreateXxxEditor(Mode, InitToolkitHost, Asset)
  │  ← 모듈 인터페이스의 팩토리 메서드
  ▼
[Editor] InitXxxEditor(Mode, InitToolkitHost, Asset)
  │
  ├─ 편집 대상 저장 (멤버 변수에 UObject* 보관)
  ├─ BindCommands() — UICommandList에 액션 바인딩
  ├─ ExtendToolBar() — 툴바 확장
  ├─ ExtendMenu() — 메뉴 확장 (옵션)
  │
  ├─ FTabManager::FLayout 정의 (탭 배치)
  │    └─ Viewport, Properties, SocketManager 등 탭 위치 지정
  │
  └─ InitAssetEditor(Mode, Host, AppIdentifier, Layout, ..., Asset)
       ← FAssetEditorToolkit 기본 초기화 호출 (반드시 마지막)
```

### 1.4 탭 구성 비교

| 에디터 | 탭 ID | 역할 |
|--------|--------|------|
| **StaticMesh** | ViewportTabId | 3D 프리뷰 뷰포트 |
| | PropertiesTabId | IDetailsView (프로퍼티 편집) |
| | SocketManagerTabId | 소켓 관리 |
| | CollisionTabId | 충돌 설정 (Convex Decomposition) |
| | PreviewSceneSettingsTabId | 프리뷰 씬 설정 |
| | SecondaryToolbarTabId | 보조 툴바 |
| **SkeletalMesh** | ViewportTab | Persona 뷰포트 |
| | DetailsTab | 디테일 패널 |
| | SkeletonTreeTab | 스켈레톤 트리 |
| | MorphTargetsTab | 모프 타겟 |
| | MeshDetailsTab | 메시 상세 |
| | AdvancedPreviewTab | 프리뷰 씬 설정 |
| | AssetDetailsTab | 에셋 상세 |
| | AnimationMappingTab | 애니메이션 매핑 |
| **Texture** | ViewportTabId | 텍스처 프리뷰 |
| | PropertiesTabId | 텍스처 프로퍼티 |

## 2. 프리뷰 뷰포트 + 디테일 패널 조합 구조

### 2.1 StaticMeshEditor — 전형적 뷰포트+디테일 조합

```
FStaticMeshEditor
  │
  ├─ SStaticMeshEditorViewport (뷰포트 위젯)
  │    └─ FStaticMeshEditorViewportClient (FEditorViewportClient 상속)
  │         ├─ UStaticMeshComponent 렌더링
  │         ├─ 충돌 시각화 (Simple/Complex)
  │         ├─ 노멀/탄젠트/바이노멀 표시
  │         ├─ 소켓 표시
  │         └─ 와이어프레임/버텍스 컬러 모드
  │
  ├─ IDetailsView (StaticMeshDetailsView)
  │    └─ UStaticMesh의 UPROPERTY 자동 열거
  │         ├─ LOD 설정
  │         ├─ 머티리얼 슬롯
  │         ├─ 충돌 설정
  │         └─ 라이트맵 설정
  │
  ├─ ISocketManager (소켓 편집 전용 패널)
  │
  └─ SConvexDecomposition (충돌 생성 전용 패널)
       └─ DoDecomp(HullCount, MaxVerts, Precision) → V-HACD 비동기 분해
```

**뷰포트 토글 상태 (bool 멤버):**
```
bDrawNormals, bDrawTangents, bDrawBinormals, bDrawPivots,
bDrawVertices, bDrawGrids, bDrawBounds, bDrawSimpleCollisions,
bDrawComplexCollisions, bDrawSockets, bDrawWireframes,
bDrawVertexColors, bDrawAdditionalData
```

### 2.2 SkeletalMeshEditor — Persona 통합 뷰포트

```
FSkeletalMeshEditor
  │
  ├─ IPersonaToolkit (Persona 시스템 통합)
  │    └─ 스켈레톤, 애니메이션, 메시를 통합 관리하는 공유 툴킷
  │
  ├─ IPersonaViewport (뷰포트)
  │    └─ 스켈레탈 메시 + 본 시각화 + 클로스 시뮬레이션
  │
  ├─ ISkeletonTree (스켈레톤 트리 패널)
  │    └─ 본 계층 구조 편집
  │
  ├─ IDetailsView (DetailsView)
  │    └─ 선택된 본/소켓/에셋 프로퍼티
  │
  └─ FSkeletalMeshEditorMode (FApplicationMode)
       └─ 워크플로우 기반 탭 팩토리 관리
            ├─ FMeshPropertiesSummoner (메시 프로퍼티 탭)
            └─ FMeshControllerMappingTabSummoner (애니메이션 매핑 탭)
```

**차이점:** SkeletalMeshEditor는 `FWorkflowCentricApplication`을 통해 **모드 기반 UI**를 사용. `FApplicationMode`가 탭 세트를 정의하고, 모드 전환 시 탭 구성이 바뀜.

### 2.3 TextureEditor — 2D 뷰포트 특화

```
FTextureEditorToolkit
  │
  ├─ STextureEditorViewport (2D 텍스처 프리뷰)
  │    └─ FTextureEditorViewportClient
  │         ├─ 채널 토글 (R/G/B/A/Desaturation)
  │         ├─ 줌 모드 (Custom/Fit/Fill)
  │         ├─ MipLevel 선택
  │         ├─ Layer 선택 (텍스처 배열)
  │         ├─ 볼륨 텍스처 Opacity/Orientation
  │         └─ 체커보드/단색 배경
  │
  └─ IDetailsView (TexturePropertiesWidget)
       └─ UTexture의 UPROPERTY (압축, 필터링, LOD 설정 등)
       └─ Quick Info 텍스트 (해상도, 포맷, 밉맵 수, 알파 채널 유무 등)
```

## 3. AssetTools의 에셋 생성/임포트/익스포트 프레임워크

### 3.1 모듈 구조

```
FAssetToolsModule : IModuleInterface
  └─ UAssetToolsImpl : UObject, IAssetTools  (실제 구현, UCLASS)
       ├─ TArray<TSharedRef<IAssetTypeActions>>  ← 등록된 에셋 타입 액션 목록
       ├─ TArray<TSharedRef<IClassTypeActions>>   ← 클래스 타입 액션 목록
       ├─ FAssetRenameManager                    ← 에셋 이름 변경 관리
       ├─ FAssetFixUpRedirectors                 ← 리다이렉터 정리
       └─ TMap<FName, EAssetTypeCategories::Type> ← 커스텀 카테고리 맵
```

### 3.2 IAssetTypeActions — 에셋 타입 등록 인터페이스

에셋 타입마다 하나의 `IAssetTypeActions` 구현이 등록됨.

```
IAssetTypeActions (인터페이스)
  └─ FAssetTypeActions_Base (기본 구현, 대부분 여기서 상속)
       ├─ FAssetTypeActions_StaticMesh
       ├─ FAssetTypeActions_SkeletalMesh
       ├─ FAssetTypeActions_Texture
       ├─ FAssetTypeActions_Material
       └─ ... (수십 개 타입)
```

**핵심 메서드와 역할:**

| 메서드 | 역할 | 예시 (StaticMesh) |
|--------|------|-------------------|
| `GetName()` | 표시 이름 | "Static Mesh" |
| `GetTypeColor()` | 콘텐츠 브라우저 색상 | FColor(0,255,255) — 시안 |
| `GetSupportedClass()` | 대상 UClass | UStaticMesh::StaticClass() |
| `GetCategories()` | 카테고리 비트 | EAssetTypeCategories::Basic |
| `OpenAssetEditor()` | 에디터 오픈 | StaticMeshEditor 모듈의 CreateStaticMeshEditor() 호출 |
| `HasActions()` | 컨텍스트 메뉴 지원 여부 | true |
| `GetActions()` | 컨텍스트 메뉴 항목 | LOD 임포트, 충돌 복사 등 |
| `GetThumbnailInfo()` | 썸네일 정보 | UThumbnailInfo 반환 |
| `IsImportedAsset()` | 외부 임포트 여부 | true |
| `GetResolvedSourceFilePaths()` | 원본 파일 경로 | FBX 경로 등 |

### 3.3 에셋 생성 흐름

```
[사용자] 콘텐츠 브라우저 → 우클릭 → "새 에셋 생성"
  │
  ▼
[AssetTools] IAssetTools::CreateAssetWithDialog(Name, Path, Class, Factory)
  │
  ├─ UFactory 서브클래스가 에셋 생성 담당
  │    ├─ FactoryCreateNew() — 코드로 새로 생성
  │    └─ FactoryCreateBinary/Text() — 파일에서 임포트
  │
  ├─ 패키지 이름 유효성 검사
  ├─ 중복 검사 → CreateUniqueAssetName()
  │
  └─ UObject* 반환 (생성된 에셋)
```

### 3.4 임포트 흐름

```
[방법 1] ImportAssetsWithDialog(DestinationPath)
  │  파일 선택 다이얼로그 → UFactory 자동 매칭 → 임포트
  │
[방법 2] ImportAssets(Files, DestinationPath, Factory)
  │  프로그래밍 방식 직접 호출
  │
[방법 3] ImportAssetsAutomated(UAutomatedAssetImportData)
  │  커맨드라인/자동화 전용, UI 없음
  │
[방법 4] ImportAssetTasks(TArray<UAssetImportTask*>)
  │  스크립트/BP 노출용 태스크 기반
  │
  ▼
공통 내부: FAssetImportParams 구성
  ├─ SpecifiedFactory — 사용할 팩토리
  ├─ bSyncToBrowser — 임포트 후 브라우저 동기화
  ├─ bForceOverrideExisting — 기존 에셋 덮어쓰기

```

## 4. 새로운 에셋 타입의 에디터를 추가하는 흐름

### 4.1 전체 흐름 (5단계)

```
[1단계] UObject 서브클래스 정의 (에셋 데이터 클래스)
  │  UCLASS()로 에셋 타입 정의 + UPROPERTY()로 프로퍼티 선언
  │
  ▼
[2단계] UFactory 서브클래스 정의 (생성/임포트)
  │  FactoryCreateNew() 또는 FactoryCreateBinary()로 에셋 인스턴스 생성
  │
  ▼
[3단계] FAssetTypeActions 서브클래스 정의 (에셋 타입 등록)
  │  FAssetTypeActions_Base 상속
  │  ├─ GetName(), GetSupportedClass(), GetTypeColor(), GetCategories() 구현
  │  └─ OpenAssetEditor() — 전용 에디터 모듈의 CreateXxxEditor() 호출
  │
  ▼
[4단계] 에셋 에디터 모듈 정의 (전용 에디터)
  │
  │  [4-a] 에디터 모듈 인터페이스
  │  class IMyAssetEditorModule : public IModuleInterface,
  │      public IHasMenuExtensibility, public IHasToolBarExtensibility {
  │      virtual TSharedRef<IMyAssetEditor> CreateEditor(Mode, Host, Asset) = 0;
  │  };
  │
  │  [4-b] 에디터 인터페이스 (Public)
  │  class IMyAssetEditor : public FAssetEditorToolkit {
  │      virtual UMyAsset* GetAsset() = 0;  // 편집 대상 접근
  │  };
  │
  │  [4-c] 에디터 구현 (Private)
  │  class FMyAssetEditor : public IMyAssetEditor, public FGCObject,
  │      public FEditorUndoClient {
  │      ├─ InitMyAssetEditor(Mode, Host, Asset)
  │      │    ├─ 에셋 저장
  │      │    ├─ BindCommands()
  │      │    ├─ ExtendToolBar()
  │      │    ├─ FTabManager::FLayout 정의
  │      │    └─ InitAssetEditor() 호출
  │      ├─ RegisterTabSpawners() — SpawnTab_Viewport, SpawnTab_Properties
  │      └─ AddReferencedObjects() — GC 보호
  │  };
  │
  ▼
[5단계] 모듈 StartupModule()에서 등록
  │
  ├─ FAssetToolsModule::Get().RegisterAssetTypeActions(AssetTypeActions)
  │    ← 에셋 타입 액션 등록
  │
  └─ (선택) PropertyEditor에 커스텀 디테일 등록
       ← IDetailCustomization 또는 IPropertyTypeCustomization
```

### 4.2 OpenAssetEditor() 구현 패턴

```cpp
// FAssetTypeActions_StaticMesh::OpenAssetEditor() 패턴
void OpenAssetEditor(const TArray<UObject*>& InObjects,
                     TSharedPtr<IToolkitHost> EditWithinLevelEditor) override
{
    // 모듈 로드
    FMyEditorModule& EditorModule =
        FModuleManager::LoadModuleChecked<FMyEditorModule>("MyEditor");

    for (UObject* Obj : InObjects) {
        UMyAsset* Asset = Cast<UMyAsset>(Obj);
        if (Asset) {
            EditorModule.CreateEditor(
                EditWithinLevelEditor.IsValid()
                    ? EToolkitMode::WorldCentric
                    : EToolkitMode::Standalone,
                EditWithinLevelEditor,
                Asset
            );
        }
    }
}
```

### 4.3 두 가지 에디터 아키텍처 선택

| 방식 | 기반 클래스 | 특징 | 사용 예 |
|------|------------|------|---------|
| **직접 상속** | `FAssetEditorToolkit` | 단순, 고정된 탭 레이아웃 | StaticMeshEditor, TextureEditor |
| **워크플로우 기반** | `FWorkflowCentricApplication` | 모드 전환, 동적 탭 세트 | SkeletalMeshEditor, BlueprintEditor |

**직접 상속 방식:** 탭을 `RegisterTabSpawners()`에서 직접 등록, `FTabManager::FLayout`으로 고정 배치.

**워크플로우 방식:** `FApplicationMode` 서브클래스가 `FWorkflowAllowedTabSet`으로 모드별 허용 탭을 정의. `FWorkflowTabFactory`로 탭 생성 팩토리 관리.

### 4.4 ImGui 에셋 에디터 구현 시 참고

| UE4 패턴 | ImGui 대응 |
|----------|-----------|
| `FAssetEditorToolkit` | 에디터 기본 클래스 (DockSpace ID + 탭 등록 관리) |
| `RegisterTabSpawners` | ImGui::DockBuilderAddNode + 패널 등록 함수 테이블 |
| `IAssetTypeActions` | `std::unordered_map<TypeID, EditorFactory>` |
| `OpenAssetEditor` | 타입별 에디터 인스턴스 생성 + 윈도우 오픈 |
| `FEditorViewportClient` | 자체 뷰포트 렌더 타겟 + ImGui::Image() |
| `IDetailsView` | 리플렉션 기반 자동 프로퍼티 그리드 |
| `EToolkitMode` | 독립 ImGui 윈도우 vs 메인 DockSpace 내 탭 |
