## 2. RHI 리소스 타입 계층

`RHIResources.h` 기준. 모든 RHI 리소스는 `FRHIResource`를 상속.

```
FRHIResource                          ← 참조 카운팅 기반, 지연 삭제 지원
├── FRHISamplerState                  ← 텍스처 샘플러 상태
├── FRHIRasterizerState               ← 래스터라이저 상태
├── FRHIDepthStencilState             ← 깊이/스텐실 상태
├── FRHIBlendState                    ← 블렌드 상태
├── FRHIVertexDeclaration             ← 정점 선언
├── FRHIBoundShaderState              ← 바운드 셰이더 (레거시)
│
├── FRHIShader                        ← 셰이더 기본 클래스
│   ├── FRHIGraphicsShader            ← 그래픽스 셰이더 기본
│   │   ├── FRHIVertexShader
│   │   ├── FRHIHullShader
│   │   ├── FRHIDomainShader
│   │   ├── FRHIPixelShader

│
├── FRHIGraphicsPipelineState         ← 그래픽스 PSO
├── FRHIComputePipelineState          ← 컴퓨트 PSO

│
├── FRHIUniformBuffer                 ← 상수 버퍼
├── FRHIIndexBuffer                   ← 인덱스 버퍼
├── FRHIVertexBuffer                  ← 버텍스 버퍼
├── FRHIStructuredBuffer              ← 구조화 버퍼
│
├── FRHITexture                       ← 텍스처 기본 클래스
│   ├── FRHITexture2D
│   │   └── FRHITexture2DArray
│   ├── FRHITexture3D
│   ├── FRHITextureCube

```

### FRHIResource 핵심 특성 (`RHIResources.h:32`)

- **참조 카운팅**: `AddRef()` / `Release()` — `FThreadSafeCounter` 사용
- **지연 삭제**: `DeferDelete()` → `PendingDeletes` 리스트에 추가, GPU 완료 후 삭제
  - `GRHINeedsExtraDeletionLatency` 또는 RHI 스레드 분리 시 활성화
  - `FlushPendingDeletes()` 정적 함수로 프레임 단위 정리
- **Transient 리소스 추적**: `SetCommitted()` / `IsCommitted()` — 렌더 스레드 전용

### 셰이더 클래스 특이 사항

- `FRHIShader` (`RHIResources.h:455`): `Frequency`(EShaderFrequency), `Hash`(FSHAHash) 보유
- `FRHIComputeShader` (`RHIResources.h:526`): `Stats` 멤버로 성능 프로파일링 지원

### 버퍼 클래스 공통 패턴

- `FRHIIndexBuffer`: `Stride`(2 or 4), `Size`, `Usage` 보유
- `FRHIVertexBuffer`: `Size`, `Usage` 보유
- `FRHIStructuredBuffer`: `Stride`, `Size`, `Usage` 보유

### 텍스처 클래스 (`RHIResources.h:964`)

- `FRHITexture`: `NumMips`, `NumSamples`, `Format`(EPixelFormat), `Flags`(ETextureCreateFlags), `ClearValue`(FClearValueBinding)
- `FRHITexture2D`: `SizeX`, `SizeY` 추가
- `FRHITexture2DArray`: `FRHITexture2D` 상속, `SizeZ` (배열 크기) 추가
- `FRHITexture3D`: `SizeX`, `SizeY`, `SizeZ`
- `FRHITextureCube`: `Size` (한 면의 너비/높이)

## 3. FRHICommandList 역할과 구조

`RHICommandList.h` 기준. RHI 명령을 기록(recording)하고, 나중에 RHI 스레드에서 실행(execute)하는 커맨드 버퍼 시스템.

### 3-1. 클래스 계층

```
FRHICommandListBase : FNoncopyable       ← 커맨드 메모리 관리, 큐잉 기본 (line 407)
├── FRHIComputeCommandList               ← 컴퓨트 전용 명령 (line 2296)
│   ├── FRHICommandList                  ← 그래픽스 명령 추가 (line 2890)
│   │   ├── FRHICommandListImmediate     ← 싱글턴, 즉시 실행 / RHI 스레드 전송 (line 3885)
│   │   └── FRHICommandList_RecursiveHazardous  ← 재귀 호출 안전 (line 4924)
│   ├── FRHIAsyncComputeCommandListImmediate    ← 비동기 컴퓨트 전용 (line 4909)
│   └── FRHIComputeCommandList_RecursiveHazardous  (line 4980)

FRHICommandListExecutor  (별도 클래스)   ← 실행기, Immediate 커맨드리스트 소유 (line 5037)
```

### 3-2. FRHICommandListBase (`RHICommandList.h:407`)

- **메모리 관리**: `FMemStackBase MemManager` — 스택 할당자로 커맨드 메모리 관리
- **커맨드 링크드리스트**: `FRHICommandBase* Root` → `CommandLink` 체인
- **Alloc/AllocCommand**: 커맨드 객체를 MemStack에 할당, 링크드리스트에 연결
- **Bypass 모드**: RHI 스레드 없을 때 직접 실행 (`Bypass()` → `IRHICommandContext`로 바로 전달)
- **주요 상태**: `bExecuting`, `NumCommands`, `UID`
- **GPU 마스크**: `FRHIGPUMask` — Multi-GPU(SLI/CrossFire) 지원

### 3-3. FRHIComputeCommandList (`RHICommandList.h:2296`)

컴퓨트 관련 명령 기록:
- `SetShaderUniformBuffer`, `SetShaderTexture`, `SetShaderSampler`, `SetUAVParameter`
- `DispatchComputeShader(GroupX, GroupY, GroupZ)`
- `DispatchIndirectComputeShader(ArgumentBuffer, Offset)`
- `SetComputePipelineState(ComputeShader)`

### 3-4. FRHICommandList (`RHICommandList.h:2890`)

그래픽스 명령 추가:
- **드로우**: `DrawPrimitive`, `DrawIndexedPrimitive`, `DrawPrimitiveIndirect`, `DrawIndexedIndirect`
- **상태 설정**: `SetStreamSource`, `SetViewport`, `SetScissorRect`, `SetGraphicsPipelineState`
- **렌더 패스**: `BeginRenderPass`, `EndRenderPass`
- **뷰포트**: `BeginDrawingViewport`, `EndDrawingViewport`
- **트랜지션**: `BeginTransitions`, `EndTransitions`

### 3-5. FRHICommandListImmediate (`RHICommandList.h:3885`)

- **싱글턴**: `FRHICommandListExecutor::GetImmediateCommandList()`으로 접근
- **즉시 실행**: `ImmediateFlush(FlushType)` — 기록된 명령을 RHI 스레드로 전송 또는 즉시 실행
- **RHI 스레드 제어**: `StallRHIThread()` / `UnStallRHIThread()`
- **람다 커맨드**: `EnqueueLambda()` — 람다를 커맨드로 큐잉 가능
- **GPU 리소스 생성 편의 함수**: `CreateVertexBuffer`, `CreateIndexBuffer` 등 직접 포함

### 3-6. FRHICommandListExecutor (`RHICommandList.h:5037`)

- Immediate / AsyncCompute 커맨드리스트를 **소유**
- `ExecuteList(CmdList)` — 커맨드 실행 디스패치
- `LatchBypass()` — Bypass 모드 토글
- `UseParallelAlgorithms()` — 병렬 번역 가능 여부

### 3-7. 실행 흐름

```
렌더 스레드                          RHI 스레드
─────────────                       ──────────
FRHICommandList에 명령 기록
  ↓
ImmediateFlush()
  ├── Bypass=true → IRHICommandContext 직접 호출
  └── Bypass=false → 명령을 RHI 스레드로 전송
                                     FRHICommandListExecutor::ExecuteInner()
                                       ↓
                                     각 FRHICommand::ExecuteAndDestruct()
                                       ↓
                                     IRHICommandContext의 RHI* 함수 호출
```

### 3-8. IRHICommandContext (`RHIContext.h`)

실제 그래픽스 API를 호출하는 인터페이스. `IRHIComputeContext`를 상속.

주요 순수 가상 함수:
- `RHISetGraphicsPipelineState`, `RHISetComputePipelineState`
- `RHISetStreamSource`, `RHISetViewport`, `RHISetScissorRect`
- `RHIDrawPrimitive`, `RHIDrawIndexedPrimitive` (+ Indirect 변형)
- `RHIDispatchComputeShader`, `RHIDispatchIndirectComputeShader`
- `RHIBeginRenderPass`, `RHIEndRenderPass`
- `RHIBeginDrawingViewport`, `RHIEndDrawingViewport`
- `RHIBeginTransitions`, `RHIEndTransitions`

## 4. ERHIFeatureLevel 정의

`RHIDefinitions.h:220` (namespace ERHIFeatureLevel)

```cpp
namespace ERHIFeatureLevel
{
    enum Type
    {
        ES2_REMOVED,   // OpenGL ES2 (Deprecated/제거됨)
        ES3_1,         // OpenGL ES3.1 / Metal / Vulkan 기본
        SM4_REMOVED,   // DX10 SM4 (지원 완전 제거됨)
        SM5,           // DX11 SM5
        Num
    };
};
```

### 각 레벨의 의미

| 레벨 | 설명 |
|------|------|
| `ES2_REMOVED` | OpenGL ES2 기반 — UE4 4.27에서 제거됨 |
| `ES3_1` | OpenGL ES3.1, Metal, Vulkan의 핵심 기능. 모바일 타깃 |
| `SM4_REMOVED` | DX10 SM4 — 지원 완전 제거. enum 값만 잔존 |
| **`SM5`** | **DX11 SM5** — 컴퓨트 셰이더(공유 메모리, 그룹 동기화, UAV 쓰기, 정수 아토믹), Indirect 드로잉, 픽셀 셰이더 UAV 쓰기, 큐브맵 배열, 읽기 전용 깊이/스텐실 뷰. **테셀레이션은 별도 capability 플래그** |

### 관련 전역 변수 (`RHI.h`)

- `GMaxRHIFeatureLevel` — 현재 RHI가 지원하는 최대 피처 레벨
- `GMaxRHIShaderPlatform` — 현재 최대 셰이더 플랫폼

### EShaderPlatform과의 관계

`EShaderPlatform`은 셰이더 컴파일 타깃을 정의. `ERHIFeatureLevel`은 **런타임 기능 수준**.
예: `SP_PCD3D_SM5` → `ERHIFeatureLevel::SM5`, `SP_PCD3D_ES3_1` → `ERHIFeatureLevel::ES3_1`

`FGenericDataDrivenShaderPlatformInfo`가 `MaxFeatureLevel` 멤버로 플랫폼별 최대 피처 레벨을 보유.

### EShaderFrequency (`RHIDefinitions.h:27`)

```
SF_Vertex=0, SF_Hull=1, SF_Domain=2, SF_Pixel=3, SF_Geometry=4,
SF_Compute=5, SF_RayGen=6, SF_RayMiss=7, SF_RayHitGroup=8, SF_RayCallable=9
```
- 표준 SM5 그래픽스: 0~4 (5개)
- 표준 SM5 포함 컴퓨트: 0~5 (6개)
- 레이트레이싱: 6~9
