> 분석 대상: UE4 4.27 `Source/Editor/` 중 Sequencer, SequencerWidgets, CurveEditor 모듈의 .h 파일
> 선행: [14-1] 구조파악 결과 참조

## 1. 시퀀서의 트랙/섹션/키프레임 데이터 모델

### 1.1 데이터 계층 구조

```
UMovieSceneSequence              ← 시퀀스 에셋 (최상위)
  └─ UMovieScene                 ← 실제 데이터 컨테이너
       ├─ FMovieSceneBinding[]   ← 오브젝트 바인딩 (액터 ↔ 트랙 연결)
       │    └─ UMovieSceneTrack[]
       ├─ UMovieSceneTrack[]     ← 마스터 트랙 (오브젝트에 바인딩되지 않는 트랙)
       └─ UMovieSceneFolder[]    ← 폴더 (정리용)

UMovieSceneTrack                 ← 트랙 (Transform, Animation 등)
  └─ UMovieSceneSection[]        ← 섹션 (타임라인 위 막대 하나)
       └─ FMovieSceneChannelProxy
            └─ FMovieSceneChannel[] ← 채널 (실제 키프레임 데이터)
```

### 1.2 핵심 런타임 클래스

| 클래스 | 역할 |
|--------|------|
| `UMovieSceneSequence` | 시퀀스 에셋의 기본 클래스. 바인딩 해석, 스폰 관리 |
| `UMovieScene` | 트랙/바인딩/폴더를 실제로 소유. 재생 범위, 표시 레이트, 마크 프레임 관리 |
| `UMovieSceneTrack` | 트랙 기본 클래스. 다중 행(Row) 지원, 이징, 블렌딩 |
| `UMovieSceneSection` | 섹션. `TRange<FFrameNumber>` 범위, 이징, 블렌드 타입 소유 |
| `FMovieSceneChannel` | 키프레임 채널 인터페이스. 시간/값 쌍의 배열 |
| `FMovieSceneChannelProxy` | 섹션 내 모든 채널을 타입별로 관리하는 프록시 |

### 1.3 섹션의 시간 관리

`UMovieSceneSection`은 `FMovieSceneFrameRange` (`SectionRange`, 내부에 `TRange<FFrameNumber> Value` 소유)로 범위를 관리한다.

| 메서드 | 역할 |
|--------|------|
| `GetRange()` | 섹션의 유효 범위 반환 |
| `SetRange(TRange<FFrameNumber>)` | 범위 설정 |
| `GetInclusiveStartFrame()` | 시작 프레임 (포함) |
| `GetExclusiveEndFrame()` | 끝 프레임 (미포함) |
| `MoveSection(FFrameNumber)` | 섹션 이동 |
| `ExpandToFrame(FFrameNumber)` | 특정 프레임까지 확장 |

### 1.4 마크 프레임

```cpp
struct FMovieSceneMarkedFrame {
    FFrameNumber FrameNumber;  // 마크 위치
    FString Label;             // 라벨
    FLinearColor Color;        // 색상
    bool bIsDeterminismFence;  // 결정론적 평가 펜스 여부
};
```

`UMovieScene`이 `TArray<FMovieSceneMarkedFrame>`으로 관리.

## 2. 타임라인 UI 위젯 구조

### 2.1 시퀀서 에디터 위젯 계층

```
SSequencer (메인 시퀀서 위젯, SCompoundWidget)
  ├─ 브레드크럼 (서브시퀀스 탐색)
  ├─ 툴바 (재생 컨트롤, 스냅 설정 등)
  ├─ SSequencerTimeSlider (상단 타임 슬라이더)
  │    └─ FSequencerTimeSliderController (입력 처리, 그리기)
  ├─ 좌측: SSequencerTrackOutliner (트랙 목록 아웃라이너)
  │    └─ SSequencerTreeView (트리뷰, 트랙/폴더/바인딩 계층)
  ├─ 우측: SSequencerTrackArea (트랙 영역)
  │    └─ SSequencerSection[] (각 섹션 위젯)
  │         └─ 키프레임 렌더링, 이징 곡선
  ├─ SSequencerSectionOverlay (플레이헤드, 선택 범위 오버레이)
  └─ SCurveEditorPanel (커브 에디터, 토글 가능)
```

### 2.2 아웃라이너 디스플레이 노드 계층

```
FSequencerDisplayNode (기본 노드, ICurveEditorTreeItem 구현)
  ├─ FSequencerRootNode          ← 심볼릭 루트
  ├─ FSequencerFolderNode        ← 폴더
  ├─ FSequencerObjectBindingNode ← 오브젝트 바인딩 (액터)
  ├─ FSequencerTrackNode         ← 트랙 (다중 행 지원, ESubTrackMode)
  ├─ FSequencerSectionKeyAreaNode← 키 영역 (채널별)
  └─ FSequencerSectionCategoryNode← 카테고리 (채널 그룹)
```

**노드 타입 (`ESequencerNode::Type`):** Object, Track, KeyArea, Category, Root, Folder

**정렬 (`EDisplayNodeSortType`):** Folders → Tracks → ObjectBindings → CameraCuts → Shots

### 2.3 FSequencerNodeTree

트랙 아웃라이너의 노드 트리 전체를 관리. `FSequencer`가 소유.

| 메서드 | 역할 |
|--------|------|
| `Update()` | MovieScene 데이터로부터 트리 갱신 |
| `GetRootNodes()` | UI에 표시할 루트 노드 배열 |
| `FilterNodes(InFilter)` | 텍스트 필터 적용 |
| `IsNodeFiltered(Node)` | 노드가 필터링되었는지 확인 |
| `SaveExpansionState()` | 노드 확장 상태 저장 |
| `SavePinnedState()` | 노드 핀 상태 저장 |

### 2.4 ITimeSliderController & FSequencerTimeSliderController

타임라인 눈금/스크러버 입력/렌더링의 핵심 컨트롤러.

| 가상 함수 | 역할 |
|-----------|------|
| `OnPaintTimeSlider()` | 눈금, 숫자 라벨, 스크러버 그리기 |
| `OnPaintViewArea()` | 재생 범위, 마크 프레임 시각화 |
| `SetViewRange()` | 보이는 시간 범위 설정 (애니메이션 보간 가능) |
| `SetScrubPosition()` | 스크러버 위치 설정 |
| `GetDisplayRate()` / `GetTickResolution()` | 표시 프레임레이트 / 틱 해상도 |

**시간 관련 타입:**

| 타입 | 역할 |
|------|------|
| `FFrameNumber` | 정수 프레임 번호 |
| `FFrameTime` | 프레임 + 서브프레임 (float) |
| `FFrameRate` | 프레임레이트 (Numerator/Denominator) |
| `FQualifiedFrameTime` | `FFrameTime` + `FFrameRate` |
| `FAnimatedRange` | `TRange<double>` + 애니메이션 타겟 |

### 2.5 SSequencer의 주요 Slate 속성

| 속성 | 역할 |
|------|------|
| `ViewRange` | 보이는 시간 범위 (초) |
| `ClampRange` | 스크롤 제한 범위 |
| `PlaybackRange` | 재생 범위 (`TRange<FFrameNumber>`) |
| `SelectionRange` | 선택 범위 |
| `ScrubPosition` | 현재 재생 헤드 위치 |
| `MarkedFrames` | 마크된 프레임 배열 |
| `SubSequenceRange` | 서브시퀀스 범위 |

### 2.6 레이아웃 상수 (SequencerLayoutConstants)

| 상수 | 값 | 용도 |
|------|-----|------|
| `IndentAmount` | 10.0f | 자식 노드 들여쓰기 |
| `FolderNodeHeight` | 20.0f | 폴더 노드 높이 |
| `ObjectNodeHeight` | 20.0f | 오브젝트 노드 높이 |
| `SectionAreaDefaultHeight` | 15.0f | 섹션 영역 기본 높이 |
| `KeyAreaHeight` | 15.0f | 키 영역 높이 |

## 3. 커브 에디터의 키프레임 편집 구조

### 3.1 커브 에디터 아키텍처

```
FCurveEditor (비-UI 로직, 커브/선택/도구 관리)
  ├─ TMap<FCurveModelID, TUniquePtr<FCurveModel>> CurveData ← 모든 커브
  ├─ FCurveEditorSelection             ← 키/탄젠트 선택 상태
  ├─ FCurveEditorTree                  ← 커브 트리 (시퀀서 연동)
  ├─ ICurveEditorBounds                ← 뷰 범위 관리
  ├─ ICurveEditorToolExtension[]       ← 편집 도구 (이동, 스케일 등)
  └─ UCurveEditorSettings              ← 설정

SCurveEditorPanel (메인 UI 위젯)
  ├─ SCurveEditorTree (좌측 트리)
  ├─ SCurveEditorViewContainer (커브 뷰 컨테이너)
  │    └─ SCurveEditorView[] (뷰 인스턴스)
  ├─ SCurveKeyDetailPanel (키 프로퍼티 편집)
  └─ SCurveEditorToolProperties (도구 프로퍼티)
```

### 3.2 FCurveModel — 커브 데이터 추상화

커브 에디터가 이해하는 범용 커브 인터페이스. 구체적인 데이터(`FRichCurve` 등)를 래핑.

| 가상 함수 | 역할 |
|-----------|------|
| `GetCurve()` | 원시 커브 데이터 포인터 |
| `Modify()` | 수정 전 호출 (Undo 트랜잭션) |
| `DrawCurve(ScreenSpace, OutPoints)` | 보간 점 생성 (렌더링용) |
| `GetKeys(MinTime, MaxTime, MinValue, MaxValue)` | 범위 내 키 조회 |
| `AddKeys(Positions, Attributes)` | 키 추가 |
| `RemoveKeys(KeyHandles)` | 키 삭제 |
| `GetKeyPositions(Keys)` / `SetKeyPositions(Keys)` | 키 위치 읽기/쓰기 |
| `GetKeyAttributes(Keys)` / `SetKeyAttributes(Keys)` | 보간 속성 읽기/쓰기 |
| `Evaluate(Time)` | 특정 시간의 값 평가 |
| `GetTimeRange()` / `GetValueRange()` | 시간/값 범위 |

**커브 속성:** Color, IntentionName, LongDisplayName, ShortDisplayName, SupportedViews

### 3.3 IKeyArea — 시퀀서 키 영역

시퀀서 측에서 `FMovieSceneChannelHandle`을 래핑하여 커브 에디터와 연결하는 브릿지.

| 메서드 | 역할 |
|--------|------|
| `AddOrUpdateKey(Time, ObjectBindingID)` | 키 추가/갱신 |
| `DuplicateKey(Handle)` | 키 복제 |
| `GetKeyTimes()` / `SetKeyTimes()` | 키 시간 읽기/쓰기 |
| `DrawKeys(Handles, OutDrawParams)` | 키 그리기 정보 |
| `CreateCurveEditorModel(Sequencer)` | `FCurveModel` 생성 (커브 에디터 연동) |
| `CreateKeyEditor(Sequencer, ObjectBindingID)` | 인라인 키 에디터 위젯 생성 |

### 3.4 커브 뷰 타입 (`ECurveEditorViewID`)

| 뷰 | 설명 |
|----|------|
| `Absolute` | 단일 2D 스크롤 격자, 절대값 표시 |
| `Normalized` | 수평 스크롤, 모든 커브가 뷰 범위로 정규화 |
| `Stacked` | 수평 스크롤, 각 커브가 별도 고정 높이 격자에 정규화 |
| `CUSTOM_START` | 외부 플러그인 등록 뷰의 시작 ID |

### 3.5 키/탄젠트 포인트 타입 (`ECurvePointType`)

| 타입 | 값 | 설명 |
|------|-----|------|
| `Key` | 0x001 | 키프레임 본체 |
| `ArriveTangent` | 0x002 | 도착 탄젠트 핸들 |
| `LeaveTangent` | 0x004 | 출발 탄젠트 핸들 |

### 3.6 커브 에디터 도구/필터

**도구 (`ICurveEditorToolExtension`):** `FCurveEditorToolID`로 식별. `MakeToolActive()`로 활성화, 한 번에 하나만 활성.

**필터 (`UCurveEditorFilterBase`):** UObject 기반, CDO를 직접 편집. `UPROPERTY(EditAnywhere)`로 파라미터 노출.

| 내장 필터 | 역할 |
|-----------|------|
| `UCurveEditorBakeFilter` | 커브를 일정 간격 키로 베이크 |
| `UCurveEditorReduceFilter` | 허용 오차 내에서 키 수 줄이기 |
| `UCurveEditorEulerFilter` | 오일러 각도 필터 (짐벌 락 보정) |

### 3.7 스크린 스페이스 변환 (`FCurveEditorScreenSpace`)

픽셀 좌표 ↔ 커브 입력/출력 좌표 변환. 뷰별 ViewSpace와 커브별 `ViewToCurveTransform`의 2단계 변환.

### 3.8 드래그 오퍼레이션 (`ICurveEditorDragOperation`)

| 드래그 | 역할 |
|--------|------|
| `Marquee` | 사각형 선택 |
| `MoveKeys` | 키 이동 |
| `Pan` | 뷰 팬 |
| `Tangent` | 탄젠트 핸들 조정 |
| `Zoom` | 뷰 줌 |

## 4. ImGui로 타임라인 UI를 만들 때 참고할 구조

### 4.1 UE4 시퀀서와 ImGui 대응 구조

| UE4 시퀀서 요소 | ImGui 구현 접근 |
|-----------------|----------------|
| `SSequencer` (메인 위젯) | ImGui 윈도우 + 커스텀 드로잉 |
| `SSequencerTimeSlider` (눈금 바) | `ImDrawList`로 직접 눈금/숫자 그리기 |
| `SSequencerTrackOutliner` (좌측 트리) | `ImGui::TreeNode` 기반 트리 |
| `SSequencerTrackArea` (섹션 영역) | `ImDrawList`로 색상 막대 + 키 다이아몬드 그리기 |
| `SCurveEditorPanel` (커브 에디터) | `ImDrawList` 커브 렌더링 또는 ImPlot 연동 |
| `FSequencerTimeSliderController` | 자체 타임 슬라이더 컨트롤러 클래스 |
| `FCurveEditor` | 자체 커브 에디터 로직 클래스 |

### 4.2 데이터 모델 설계 권장

```
TimelineSequence (UMovieScene 대응)
  ├─ tracks: vector<TimelineTrack>
  ├─ playbackRange: FrameRange
  ├─ displayRate: FrameRate
  └─ markedFrames: vector<MarkedFrame>

TimelineTrack (UMovieSceneTrack 대응)
  ├─ name: string
  ├─ sections: vector<TimelineSection>
  └─ type: TrackType

TimelineSection (UMovieSceneSection 대응)
  ├─ range: FrameRange
  ├─ channels: vector<AnimChannel>
  └─ blendType: BlendType

AnimChannel (FMovieSceneChannel 대응)
  ├─ keys: vector<Keyframe>    // 시간순 정렬
  └─ interpolation: InterpMode // Linear, Cubic 등

Keyframe
  ├─ time: FrameNumber
  ├─ value: float
  ├─ arriveTangent, leaveTangent: float
  └─ interpMode: InterpMode
```

### 4.3 핵심 구현 포인트

**1. 타임라인 눈금 렌더링:**
- `FSequencerTimeSliderController::DetermineOptimalSpacing()` 참고
- 픽셀 밀도에 따라 눈금 간격 자동 조정
- ImGui에서는 `ImDrawList::AddLine()` + `AddText()`로 눈금/라벨 직접 그리기

**2. 섹션 드래그/리사이즈:**
- `ISequencerSection::ResizeSection()`, `SlipSection()`, `DilateSection()` 참고
- Leading/Trailing 엣지 구분 (`ESequencerSectionResizeMode`)
- 스냅 모드: 없음, 간격 스냅, 키 스냅 (`ESnapTimeMode`)

**3. 키프레임 편집:**
- UE4는 `FKeyHandle`로 키를 식별하고 `IKeyArea`를 통해 CRUD
- ImGui에서는 키 인덱스 또는 자체 핸들 시스템으로 단순화 가능
- 키 선택은 `FCurveEditorSelection` 처럼 `Map<CurveID, Set<KeyHandle>>` 구조 권장

**4. 커브 에디터 연동:**
- 시퀀서 트랙 선택 → 해당 채널의 `FCurveModel` 생성 → 커브 에디터에 추가
- `FCurveEditorSelection`과 시퀀서 선택을 양방향 동기화
- ImGui에서는 타임라인과 커브 에디터를 같은 시간 축으로 동기화

### 4.4 최소 구현 순서

1. **데이터 모델** — Track → Section → Channel → Keyframe 계층
2. **타임라인 눈금 바** — 줌/팬, 프레임 표시, 스크러버
3. **트랙 아웃라이너** — 트리뷰, 확장/접기
4. **섹션 영역** — 색상 막대 렌더링, 드래그/리사이즈
5. **키프레임 표시** — 다이아몬드 마커, 선택/이동
6. **커브 에디터** — 베지어 보간 렌더링, 탄젠트 편집
