## 1. UObject 클래스의 상속 계층

### 1.1 기본 상속 체인

```
UObjectBase                    ← 최하위 기반, 식별/등록 담당
  └─ UObjectBaseUtility        ← 플래그/마크/이름 유틸리티
       └─ UObject              ← 실제 게임/엔진 코드가 사용하는 기반 클래스
```

### 1.2 UObjectBase — 최하위 기반 클래스

**역할:** UObject 시스템의 메모리 레이아웃과 등록을 정의하는 최하위 클래스. 게임 코드에서 직접 사용하지 않음.

**핵심 멤버 변수 (Private):**

| 멤버 | 타입 | 역할 |
|------|------|------|
| `ObjectFlags` | `EObjectFlags` | 오브젝트 상태 플래그 (Public, Transient, BeginDestroyed 등) |
| `InternalIndex` | `int32` | GUObjectArray 내부 인덱스 (고유 ID, 재사용됨) |
| `ClassPrivate` | `UClass*` | 이 오브젝트의 클래스 정보 |
| `NamePrivate` | `FName` | 오브젝트 이름 |
| `OuterPrivate` | `UObject*` | 이 오브젝트를 포함하는 외부 오브젝트 |

**핵심 메서드:**

| 메서드 | 역할 |
|--------|------|
| `GetClass()` | ClassPrivate 반환 |
| `GetOuter()` | OuterPrivate 반환 |
| `GetFName()` | NamePrivate 반환 |
| `GetUniqueID()` | InternalIndex를 uint32로 반환 |
| `GetFlags()` / `SetFlagsTo()` | ObjectFlags 읽기/쓰기 |
| `AtomicallySetFlags()` / `AtomicallyClearFlags()` | GC/로딩 스레드용 원자적 플래그 조작 |
| `AddObject()` | 이름 해시 테이블 + GUObjectArray에 등록 (Private) |
| `Register()` | 부트스트랩 등록 큐에 추가 |
| `DeferredRegister()` | 부트스트랩 → 실제 UObject 배열 등록 변환 |
| `LowLevelRename()` | 이름/Outer 변경 + 해시 재등록 (Protected) |
| `GetExternalPackage()` | 외부 패키지 연결 반환 |

**정적 초기화 지원:**
- `FCompiledInDefer` — 컴파일 시 UClass 등록을 지연 큐에 추가
- `FCompiledInDeferStruct` — UScriptStruct 지연 등록
- `FCompiledInDeferEnum` — UEnum 지연 등록
- `ProcessNewlyLoadedUObjects()` — 모듈 로드 후 지연된 오브젝트들을 실제 등록

### 1.3 UObjectBaseUtility — 유틸리티 레이어

**역할:** UObjectBase의 raw 멤버에 대한 편의 함수 제공. GUObjectArray를 통한 플래그/마크 접근.

**플래그 조작:**

| 메서드 | 역할 |
|--------|------|
| `SetFlags(NewFlags)` | 플래그 OR 추가 |
| `ClearFlags(NewFlags)` | 플래그 제거 |
| `HasAnyFlags(Flags)` | 플래그 중 하나라도 있는지 |
| `HasAllFlags(Flags)` | 모든 플래그가 있는지 |

**GC/수명 관련:**

| 메서드 | 역할 |
|--------|------|
| `IsPendingKill()` | PendingKill 플래그 확인 (GC 수집 대상) |
| `MarkPendingKill()` | PendingKill 설정 (Root가 아닌 경우만) |
| `AddToRoot()` | GC Root 추가 (수집 방지) |
| `RemoveFromRoot()` | GC Root 제거 |
| `IsRooted()` | Root 여부 확인 |
| `IsUnreachable()` | GC Mark 단계에서 미도달 여부 |
| `IsNative()` | 네이티브(C++) 오브젝트 여부 |

**이름/경로:**

| 메서드 | 역할 |
|--------|------|
| `GetFullName(StopOuter)` | `"ClassName Outer.Name"` 형식 |
| `GetPathName(StopOuter)` | `"Outer.Name"` 형식 |

**클러스터:**

| 메서드 | 역할 |
|--------|------|
| `CanBeClusterRoot()` | 클러스터 루트 가능 여부 (기본 false) |
| `CanBeInCluster()` | 클러스터 소속 가능 여부 |

### 1.4 UObject — 게임/엔진 코드의 기반 클래스

**역할:** 실제 게임/엔진 코드가 상속하는 최상위 클래스. 직렬화, 에디터 지원, 서브오브젝트, 생명주기 가상 함수 제공.

**생명주기 가상 함수:**

| 가상 함수 | 호출 시점 |
|-----------|----------|
| `PostInitProperties()` | C++ 생성자 + 프로퍼티 초기화 후 (Config 로드 포함) |
| `PostCDOContruct()` | CDO의 C++ 생성자 후 |
| `PostLoad()` | 패키지 로드 완료 후 |
| `PostLoadSubobjects()` | PostLoad 중 서브오브젝트 인스턴싱 |
| `BeginDestroy()` | 소멸 시작 (비동기 정리 시작) |
| `IsReadyForFinishDestroy()` | 비동기 정리 완료 여부 확인 |
| `FinishDestroy()` | 최종 소멸 (메모리 해제 전 마지막 호출) |

**직렬화:**

| 메서드 | 역할 |
|--------|------|
| `Serialize(FArchive&)` | 바이너리 직렬화 |
| `Serialize(FStructuredArchive::FRecord)` | 구조화 직렬화 |
| `PreSave(ITargetPlatform*)` | 저장 전 콜백 |
| `PreSaveRoot() / PostSaveRoot()` | 패키지 저장 전후 루트 오브젝트 콜백 |

**에디터 지원:**

| 메서드 | 역할 |
|--------|------|
| `Modify(bAlwaysMarkDirty)` | Undo 트랜잭션 기록 + 패키지 Dirty |
| `PreEditChange(FProperty*)` | 프로퍼티 변경 전 (Undo 저장) |
| `PostEditChangeProperty()` | 프로퍼티 변경 후 (갱신 반영) |
| `CanEditChange(FProperty*)` | 프로퍼티 편집 가능 여부 |

**서브오브젝트:**

```cpp
// 생성자 내에서 기본 서브오브젝트 생성
UMyComponent* Comp = CreateDefaultSubobject<UMyComponent>(TEXT("MyComp"));
// 에디터 전용 서브오브젝트
UDebugWidget* Debug = CreateEditorOnlyDefaultSubobject<UDebugWidget>(TEXT("Debug"));
```

## 2. 리플렉션 타입의 관계

### 2.1 전체 상속 구조

```
UObject
  └─ UField                     ← 리플렉션 데이터의 UObject 기반 (레거시)
       ├─ UStruct               ← 프로퍼티를 가질 수 있는 구조체/클래스 기반
       │    ├─ UClass           ← C++ 클래스 / Blueprint 클래스
       │    ├─ UScriptStruct    ← USTRUCT() 구조체
       │    └─ UFunction        ← UFUNCTION() 함수
       └─ UEnum                 ← UENUM() 열거형

FField (Non-UObject)             ← UE 4.25+에서 프로퍼티용 경량 리플렉션 기반
  └─ FProperty                  ← 프로퍼티 (이전 UProperty → FProperty로 이전)
       ├─ FNumericProperty       ← 숫자 (int, float 등)
       ├─ FBoolProperty          ← bool
       ├─ FObjectPropertyBase    ← UObject* 참조
       │    └─ FObjectProperty   ← 일반 UObject*
       ├─ FStructProperty        ← USTRUCT 값
       ├─ FStrProperty           ← FString
       ├─ FArrayProperty         ← TArray
       ├─ FMapProperty           ← TMap
       └─ ... (수십 개 타입)
```

### 2.2 UField — 리플렉션 기본 (UObject 기반, 레거시)

| 멤버 | 타입 | 역할 |
|------|------|------|
| `Next` | `UField*` | 링크드 리스트의 다음 필드 |

| 메서드 | 역할 |
|--------|------|
| `GetOwnerClass()` | Outer 체인에서 UClass 검색 |
| `GetOwnerStruct()` | Outer 체인에서 UStruct 검색 |
| `GetAuthoredName()` | 작성자가 부여한 이름 |

### 2.3 UStruct — 프로퍼티 컨테이너

**핵심 멤버:**

| 멤버 | 타입 | 역할 |
|------|------|------|
| `SuperStruct` | `UStruct*` | 부모 구조체/클래스 |
| `Children` | `UField*` | 자식 UField 링크드 리스트 (레거시) |
| `ChildProperties` | `FField*` | 자식 FProperty 링크드 리스트 |
| `PropertiesSize` | `int32` | 전체 프로퍼티 크기 (바이트) |
| `MinAlignment` | `int32` | 메모리 정렬 |
| `Script` | `TArray<uint8>` | 스크립트 바이트코드 |
| `PropertyLink` | `FProperty*` | 파생→기반 순 프로퍼티 링크드 리스트 |
| `RefLink` | `FProperty*` | 오브젝트 참조 프로퍼티 링크드 리스트 |
| `DestructorLink` | `FProperty*` | 소멸 필요 프로퍼티 링크드 리스트 |
| `PostConstructLink` | `FProperty*` | 생성 후 초기화 필요 프로퍼티 |

### 2.4 UClass — 클래스 리플렉션

UStruct를 상속하며, C++ 클래스의 메타데이터를 완전히 표현.

**핵심 멤버:**

| 멤버 | 타입 | 역할 |
|------|------|------|
| `ClassConstructor` | `ClassConstructorType` | C++ 생성자 함수 포인터 |
| `ClassAddReferencedObjects` | `ClassAddReferencedObjectsType` | AddReferencedObjects 정적 메서드 포인터 |
| `ClassFlags` | `EClassFlags` | 클래스 플래그 (Abstract, Transient 등) |
| `ClassCastFlags` | `EClassCastFlags` | 빠른 dynamic_cast를 위한 비트 플래그 |
| `ClassWithin` | `UClass*` | 인스턴스의 Outer 타입 제한 |
| `ClassGeneratedBy` | `UObject*` | Blueprint에 의해 생성된 경우 원본 |
| `ClassConfigName` | `FName` | Config ini 파일명 |
| `ClassDefaultObject` | `UObject*` | CDO (Class Default Object) |
| `FuncMap` | `TMap<FName, UFunction*>` | 이름→함수 매핑 |
| `Interfaces` | `TArray<FImplementedInterface>` | 구현 인터페이스 목록 |
| `ReferenceTokenStream` | `FGCReferenceTokenStream` | GC용 참조 토큰 스트림 |
| `NativeFunctionLookupTable` | `TArray<FNativeFunctionLookup>` | 네이티브 함수 테이블 |
| `SparseClassData` | `void*` | 클래스별 공유 데이터 (인스턴스별 X) |

### 2.5 UFunction — 함수 리플렉션

| 멤버 | 타입 | 역할 |
|------|------|------|
| `FunctionFlags` | `EFunctionFlags` | 함수 속성 (BlueprintCallable, Net 등) |
| `NumParms` | `uint8` | 파라미터 수 |
| `ParmsSize` | `uint16` | 파라미터 총 크기 |
| `ReturnValueOffset` | `uint16` | 반환값 프로퍼티 오프셋 |
| `RPCId / RPCResponseId` | `uint16` | 네트워크 RPC ID |
| `Func` | `FNativeFuncPtr` | C++ 함수 포인터 |

| 메서드 | 역할 |
|--------|------|
| `Invoke(Obj, Stack, Result)` | UObject에 함수 호출 실행 |
| `GetNativeFunc()` | C++ 함수 포인터 반환 |

### 2.6 UEnum — 열거형 리플렉션

| 멤버 | 역할 |
|------|------|
| `CppType` | C++ 타입 문자열 (예: "EMyEnum") |
| `Names` | `TArray<TPair<FName, int64>>` — 이름-값 쌍 (Protected) |

| 메서드 | 역할 |
|--------|------|
| `GetIndexByValue(int64)` | 값으로 인덱스 검색 |
| `GetNameByIndex(int32)` | 인덱스로 이름 반환 |
| `GetValueByName(FName)` | 이름으로 값 반환 |

### 2.7 FField / FProperty — 경량 리플렉션 시스템 (UE 4.25+)

UProperty가 UObject 기반이었으나, 성능 문제로 **FField** 기반의 **FProperty**로 이전.

**FField 핵심 멤버:**

| 멤버 | 타입 | 역할 |
|------|------|------|
| `ClassPrivate` | `FFieldClass*` | 타입 정보 (UClass 대응) |
| `Owner` | `FFieldVariant` | 소유자 (UStruct 또는 FField) |
| `Next` | `FField*` | 링크드 리스트 다음 |
| `NamePrivate` | `FName` | 이름 |
| `FlagsPrivate` | `EObjectFlags` | 플래그 |

**FFieldClass** — FField의 타입 시스템 (UClass의 경량 대응):
- `Name`, `Id`, `CastFlags`, `SuperClass`, `DefaultObject`
- `IsChildOf(FFieldClass*)` — 캐스트 플래그 기반 빠른 상속 확인

**FProperty 핵심 멤버:**

| 멤버 | 타입 | 역할 |
|------|------|------|
| `ArrayDim` | `int32` | 정적 배열 크기 (1이면 비배열) |
| `ElementSize` | `int32` | 단일 요소 크기 |
| `PropertyFlags` | `EPropertyFlags` | 프로퍼티 메타데이터 플래그 |
| `Offset_Internal` | `int32` | 구조체 내 바이트 오프셋 |
| `RepNotifyFunc` | `FName` | 리플리케이션 변경 알림 함수명 |

## 3. 가비지 컬렉션 관련 클래스/구조체

### 3.1 GC 핵심 구성 요소

```
FUObjectArray (GUObjectArray)           ← 전역 UObject 배열
  └─ FUObjectItem[]                     ← 개별 오브젝트 항목
       ├─ Object : UObjectBase*         ← 오브젝트 포인터
       ├─ Flags : int32                 ← EInternalObjectFlags
       ├─ ClusterRootIndex : int32      ← 클러스터 루트/소속 인덱스
       └─ SerialNumber : int32          ← WeakObjectPtr 시리얼 넘버
```

### 3.2 EInternalObjectFlags — 내부 오브젝트 플래그

| 플래그 | 비트 | 역할 |
|--------|------|------|
| `ReachableInCluster` | 1<<23 | 클러스터 내 외부 참조 존재 |
| `ClusterRoot` | 1<<24 | 클러스터 루트 |
| `Native` | 1<<25 | 네이티브 (UClass만 해당) |
| `Async` | 1<<26 | 게임 스레드가 아닌 다른 스레드 |
| `AsyncLoading` | 1<<27 | 비동기 로딩 중 |
| `Unreachable` | 1<<28 | Mark 단계에서 미도달 (수집 대상) |
| `PendingKill` | 1<<29 | 소멸 대기 (유효하지만 GC 수집 대상) |
| `RootSet` | 1<<30 | GC Root (절대 수집 안 됨) |
| `PendingConstruction` | 1<<31 | 클래스 생성자 미호출 |

### 3.3 EObjectFlags — GC 관련 주요 플래그

| 플래그 | 값 | 역할 |
|--------|-----|------|
| `RF_Standalone` | 0x02 | 참조 없어도 유지 (에디터) |
| `RF_Transient` | 0x40 | 저장하지 않음 |
| `RF_ClassDefaultObject` | 0x10 | CDO |
| `RF_TagGarbageTemp` | 0x100 | GC 유틸리티용 임시 플래그 |
| `RF_BeginDestroyed` | 0x8000 | BeginDestroy 호출됨 |
| `RF_FinishDestroyed` | 0x10000 | FinishDestroy 호출됨 |

### 3.4 FGCObject — Non-UObject의 GC 참여

```
FGCObject (비-UObject 기반 클래스)
  │  AddReferencedObjects(FReferenceCollector&) = 0  ← 순수 가상
  │
  ├─ 생성 시: UGCObjectReferencer::AddObject(this)
  │    └─ UGCObjectReferencer는 Root에 등록된 UObject
  │         → GC가 순회할 때 등록된 모든 FGCObject의 ARO 호출
  │
  └─ 소멸 시: UGCObjectReferencer::RemoveObject(this)
```

### 3.5 GC 참조 토큰 스트림

```
FGCReferenceTokenStream (UClass::ReferenceTokenStream)
  └─ TArray<FGCReferenceInfo>
       ├─ Type : EGCReferenceType (Object, Array, Struct 등)
       ├─ Offset : uint19 (구조체 내 바이트 오프셋)
       └─ ReturnCount : uint8 (중첩 배열 반환 깊이)
```

`EGCReferenceType` 주요 토큰:
- `GCRT_Object` — 일반 UObject* 참조
- `GCRT_ArrayObject` — TArray<UObject*>
- `GCRT_ArrayStruct` — 구조체 배열 (내부 참조 순회)
- `GCRT_WeakObject` — TWeakObjectPtr
- `GCRT_SoftObject` — TSoftObjectPtr
- `GCRT_AddReferencedObjects` — 커스텀 ARO 함수 호출

### 3.6 UObjectClusters — 클러스터 기반 GC 최적화

관련 오브젝트들을 클러스터로 묶어 GC 시 개별 순회 대신 클러스터 단위로 처리.
- `FUObjectItem::ClusterRootIndex` — 양수: 소유자, 음수: 클러스터 인덱스
- `CanBeClusterRoot()` / `CanBeInCluster()` — UObjectBaseUtility의 가상 함수

## 4. 직렬화(Serialization) 관련 인터페이스

### 4.1 핵심 직렬화 체계

```
FArchive (Core 모듈)                    ← 기본 직렬화 인터페이스
  └─ FArchiveUObject (CoreUObject)      ← UObject 전용 확장
       ├─ operator<<(FLazyObjectPtr&)
       ├─ operator<<(FSoftObjectPtr&)
       ├─ operator<<(FSoftObjectPath&)
       └─ operator<<(FWeakObjectPtr&)
```

### 4.2 UObject의 직렬화 가상 함수

| 가상 함수 | 역할 |
|-----------|------|
| `Serialize(FArchive&)` | 바이너리 직렬화 (읽기/쓰기 양방향) |
| `Serialize(FStructuredArchive::FRecord)` | 구조화 직렬화 (JSON/XML 등) |
| `PreSave(ITargetPlatform*)` | 저장 전 전처리 |
| `PostLoad()` | 로드 후 후처리 |
| `GetPreloadDependencies()` | 선행 로드 의존성 목록 |

### 4.3 링커 시스템

```
FLinkerTables                            ← 패키지 내 오브젝트 테이블
  ├─ ImportMap : TArray<FObjectImport>   ← 외부 패키지 참조
  ├─ ExportMap : TArray<FObjectExport>   ← 이 패키지가 제공하는 오브젝트
  ├─ DependsMap                          ← Export 간 의존성
  └─ SearchableNamesMap                  ← 검색 가능 이름 매핑

FLinkerLoad : FLinker                    ← 패키지 로드 전용 링커
FLinkerSave : FLinker                    ← 패키지 저장 전용 링커
```

### 4.4 패키지 파일 구조 (FPackageFileSummary)

패키지 파일(.uasset)의 헤더 정보를 담는 구조체. Tag, 버전, 압축 플래그, ImportMap/ExportMap 오프셋 등 포함.

## 5. 패키지 시스템 관련 클래스

### 5.1 UPackage — 패키지 클래스

UObject를 상속하는 패키지 컨테이너. 모든 UObject는 UPackage 안에 존재.

**핵심 멤버:**

| 멤버 | 역할 |
|------|------|
| `bDirty` | 수정 여부 (저장 필요) |
| `bHasBeenFullyLoaded` | 완전 로드 완료 여부 |
| `bCanBeImported` | 임포트 가능 여부 |
| `LoadTime` | 로드 소요 시간 |
| `FolderName` | 브라우저 폴더명 (에디터) |
| `ChunkIDs` | 스트리밍 청크 ID |

**핵심 델리게이트:**

| 델리게이트 | 역할 |
|------------|------|
| `PreSavePackageEvent` | 패키지 저장 전 |
| `PackageSavedEvent` | 패키지 저장 완료 |
| `PackageDirtyStateChangedEvent` | Dirty 상태 변경 |
| `PackageMarkedDirtyEvent` | Dirty 마킹 시 (이미 Dirty여도 호출) |

### 5.2 패키지 저장 결과 (ESavePackageResult)

| 값 | 의미 |
|----|------|
| `Success` | 저장 성공 |
| `Error` | 알 수 없는 에러 |
| `Canceled` | 사용자 취소 |
| `ContainsEditorOnlyData` | 쿠킹 시 에디터 전용 |
| `ReplaceCompletely` | 네이티브화된 에셋 |

### 5.3 오브젝트 경로 체계

```
/Game/Maps/MyLevel.MyLevel            ← 패키지 경로.에셋 이름
/Script/CoreUObject                    ← 스크립트 패키지
/Engine/Transient                      ← 임시 패키지

패키지 계층:
  UPackage ("/Game/Maps/MyLevel")
    └─ UObject ("MyLevel")             ← Outer = Package
         └─ UObject ("SubObject")      ← Outer = MyLevel
```

### 5.4 오브젝트 생성 / 검색 전역 함수

| 함수 | 역할 |
|------|------|
| `NewObject<T>(Outer, Class, Name, Flags)` | 오브젝트 생성 (→ StaticConstructObject_Internal) |
| `StaticFindObject(Class, Outer, Name)` | 이름으로 오브젝트 검색 |
| `StaticFindObjectFast(Class, Outer, Name)` | 빠른 검색 (FName 직접 비교) |
| `StaticLoadObject(Class, Outer, Name)` | 검색 + 없으면 로드 |
| `StaticConstructObject_Internal(Params)` | 내부 생성 함수 (NewObject가 호출) |

**NewObject 흐름 (헤더 기준):**
```
NewObject<T>(Outer, ...)
  └─ FStaticConstructObjectParameters 구성
       ├─ Class = T::StaticClass() 또는 지정 Class
       ├─ Outer, Name, Flags, Template
       └─ StaticConstructObject_Internal(Params) 호출
            → 구현부 확인 필요 (.cpp)
```
