## 1. AActor 상속 계층과 주요 파생 클래스

### 1.1 기본 상속 트리

```
UObject
└── AActor                          ← 월드에 배치/스폰 가능한 최상위 클래스
    ├── APawn                       ← 플레이어/AI가 빙의(Possess)할 수 있는 액터
    │   ├── ACharacter              ← 이족보행 캐릭터 (CapsuleComponent + CharacterMovementComponent + SkeletalMeshComponent)
    │   ├── ADefaultPawn            ← 기본 Pawn (구체 충돌 + FloatingPawnMovement)
    │   │   └── ASpectatorPawn      ← 관전 모드 전용 Pawn
    │   └── AWheeledVehiclePawn     ← (PhysXVehicles 모듈) 차량용 Pawn
    │
    ├── AController                 ← Pawn을 제어하는 비물리적 액터
    │   ├── APlayerController       ← 플레이어 입력 → Pawn 제어
    │   └── AAIController           ← (AIModule) AI 행동트리/BT → Pawn 제어
    │
    ├── AInfo                       ← 렌더링/충돌 없는 정보성 액터
    │   ├── AGameModeBase           ← 게임 규칙 정의 (서버 전용)
    │   │   └── AGameMode           ← 멀티플레이어 매치 기반 GameMode (상태 머신 추가)
    │   ├── AGameStateBase          ← 게임 상태 (클라이언트에 리플리케이션)
    │   │   └── AGameState          ← 매치 상태 추가
    │   ├── APlayerState            ← 플레이어별 상태 (점수, 이름 등)
    │   ├── AGameSession            ← 온라인 세션 관리
    │   └── AWorldSettings          ← 레벨별 설정 (중력, GameMode 오버라이드 등)
    │
    ├── ABrush                      ← BSP 브러시 기하
    │   └── AVolume                 ← 볼륨 (TriggerVolume, BlockingVolume 등)
    │       ├── APhysicsVolume      ← 물리 속성 영역
    │       ├── APostProcessVolume  ← 포스트프로세스 영역
    │       └── ATriggerVolume      ← 트리거 영역
    │
    ├── APlayerCameraManager        ← 카메라 관리 (뷰타겟, 카메라 쉐이크)
    ├── AHUD                        ← 2D HUD 렌더링
    ├── AStaticMeshActor            ← 스태틱 메시 배치용
    ├── ALight                      ← 라이트 액터 (DirectionalLight, PointLight, SpotLight)
    ├── ADecalActor                 ← 데칼
    ├── ALevelScriptActor           ← 레벨 블루프린트 호스트
    └── ANavigationObjectBase       ← 네비게이션 관련 (PlayerStart 등)
```

### 1.2 핵심 파생 클래스 역할 요약

| 클래스 | 파일 | 핵심 역할 |
|--------|------|-----------|
| `AActor` | GameFramework/Actor.h | 월드에 존재하는 모든 오브젝트의 기반. 컴포넌트 소유, 트랜스폼, 리플리케이션, 데미지 |
| `APawn` | GameFramework/Pawn.h | Possess/UnPossess로 Controller와 연결. 입력 수신, 이동 기반 제공 |
| `ACharacter` | GameFramework/Character.h | CapsuleComponent + CharacterMovementComponent 내장. 걷기/점프/낙하 이동 |
| `AController` | GameFramework/Controller.h | Pawn을 제어하는 두뇌 역할. ControlRotation 관리 |
| `APlayerController` | GameFramework/PlayerController.h | 입력 → Pawn 전달, 카메라 관리, HUD, CheatManager 소유 |
| `AInfo` | GameFramework/Info.h | 렌더링/충돌 없는 정보 전용 액터 기반 |

## 3. UWorld → ULevel → AActor → UActorComponent 소유 관계

### 3.1 소유 관계 다이어그램

```
UGameInstance (게임 전체 수명)
  │
  └── UWorld* OwningGameInstance (역참조)
        │
        ├── ULevel* PersistentLevel          ← 항상 로드된 기본 레벨
        ├── TSet<ULevel*> Levels             ← 스트리밍 레벨 포함 전체 목록
        ├── AGameModeBase* AuthorityGameMode ← 서버 전용 게임모드
        │
        └── ULevel (각 레벨)
              │
              ├── UWorld* OwningWorld         ← 소속 월드 역참조
              ├── TArray<AActor*> Actors      ← 레벨에 속한 모든 액터
              │
              └── AActor (각 액터)
                    │
                    ├── USceneComponent* RootComponent    ← 루트 컴포넌트
                    ├── TSet<UActorComponent*> OwnedComponents  ← 소유 컴포넌트 전체
                    │
                    └── UActorComponent (각 컴포넌트)
                          └── AActor* GetOwner()          ← 소유 액터 역참조
```

## 4. AGameModeBase, APlayerController, APawn의 역할과 관계

### 4.1 AGameModeBase (GameFramework/GameModeBase.h)

- **서버에만 존재** — 클라이언트에는 인스턴스 없음
- 게임 규칙 정의: 어떤 Pawn/Controller/HUD/GameState/PlayerState 클래스를 사용할지 결정
- 주요 책임:
  - `InitGame()` — 게임 초기화 (가장 먼저 호출)
  - `PreLogin()` / `Login()` / `PostLogin()` — 플레이어 접속 처리
  - `Logout()` — 플레이어 퇴장 처리
  - `SpawnDefaultPawnFor()` — 플레이어용 기본 Pawn 스폰
  - `RestartPlayer()` — 플레이어 리스폰
- 주요 클래스 참조 프로퍼티:
  - `DefaultPawnClass` (TSubclassOf\<APawn\>)
  - `PlayerControllerClass` (TSubclassOf\<APlayerController\>)
  - `PlayerStateClass` (TSubclassOf\<APlayerState\>)
  - `GameStateClass` (TSubclassOf\<AGameStateBase\>)
  - `HUDClass` (TSubclassOf\<AHUD\>)

**AGameMode** (AGameModeBase 파생): 매치 상태 머신 추가 (`MatchState` — EnteringMap → WaitingToStart → InProgress → WaitingPostMatch → LeavingMap)

### 4.2 APlayerController (GameFramework/PlayerController.h)

- AController 파생, 플레이어 입력을 Pawn에 전달하는 핵심 중개자
- **로컬 플레이어 1개당 1개** 존재
- 주요 소유/관리 대상:
  - `UPlayer* Player` — 로컬 플레이어 또는 네트워크 연결
  - `AHUD* MyHUD` — HUD 액터
  - `APlayerCameraManager* PlayerCameraManager` — 카메라 관리자
  - `UCheatManager* CheatManager` — 치트 관리자
  - `UInputComponent* InputComponent` — 입력 바인딩 (AActor에서 상속)
- 주요 기능:
  - 입력 처리 및 Pawn 전달
  - 카메라 관리 (뷰타겟, FOV)
  - 네트워크 RPC 처리
  - 레벨 전환, UI 입력 모드 전환

### 4.3 APawn (GameFramework/Pawn.h)

- AActor 파생 + INavAgentInterface 구현
- Controller가 Possess(빙의)하여 제어할 수 있는 액터
- 주요 특성:
  - `bUseControllerRotationPitch/Yaw/Roll` — Controller 회전 동기화 여부
  - `AutoPossessPlayer` — 레벨 시작 시 자동 빙의 설정
  - `AutoPossessAI` — AI Controller 자동 생성/빙의 시점
  - `AIControllerClass` — 사용할 AI Controller 클래스
  - `BaseEyeHeight` — 시점 높이
- 주요 함수:
  - `GetMovementComponent()` — 이동 컴포넌트 반환
  - `MakeNoise()` — AI 청각 자극

### 4.4 세 클래스 간의 관계

```
AGameModeBase (서버)
  │ 결정: 어떤 PlayerController, Pawn, GameState 클래스를 쓸지
  │ Login() → PlayerController 생성
  │ SpawnDefaultPawnFor() → Pawn 생성
  │
  ▼
APlayerController ──Possess()──▶ APawn
  │                               │
  │ 소유: HUD, CameraManager      │ 소유: MovementComponent,
  │ 처리: 입력, 카메라, UI         │       SkeletalMesh, Capsule 등
  │                               │
  └── ControlRotation ──────────▶ 회전 동기화 (bUseControllerRotation*)
```

## 5. UGameInstance의 역할

### 5.1 클래스 정보

- **파일**: `Engine/GameInstance.h`
- **상속**: `UObject`, `FExec`
- **수명**: 게임 프로세스 시작부터 종료까지 (레벨 전환에도 유지)

### 5.2 핵심 역할

| 역할 | 설명 |
|------|------|
| 전역 게임 상태 관리 | 레벨 전환(Travel)에도 파괴되지 않는 유일한 고수준 객체 |
| 로컬 플레이어 관리 | `TArray<ULocalPlayer*> LocalPlayers` — 로컬 플레이어 목록 소유 |
| 온라인 세션 | `UOnlineSession* OnlineSession` — 온라인 세션 관리 |
| 서브시스템 호스트 | `UGameInstanceSubsystem` 컬렉션 관리 |
| 레벨 전환 | Travel 명령 처리, Seamless Travel 지원 |

### 5.3 주요 가상 함수

```cpp
virtual void Init();                    // 게임 인스턴스 초기화
virtual void Shutdown();                // 종료 시 정리
virtual void StartGameInstance();       // 게임 시작
virtual void OnStart();                 // 게임 시작 직후
```

### 5.4 UWorld와의 관계

- `UWorld::OwningGameInstance` — 월드가 속한 GameInstance 역참조
- `UGameInstance` → `FWorldContext` → `UWorld` — GameInstance가 WorldContext 통해 월드 접근
- 레벨 전환 시 UWorld는 파괴/재생성되지만, UGameInstance는 유지됨
