# [14-2] Editor — 에디터 기능 요구사항 정리

> 선행: [14-1] 결과 파일
> 대상: Engine/Source/Editor/ 전체 모듈 + Engine/Source/Developer/ 전체 모듈
> 프레임워크 컨텍스트: DX11 + ImGui 에디터, FMOD 사운드

## 1. 전체 모듈 기능 카테고리 분류

### A. 뷰포트/씬 편집 (Viewport & Scene)

| 모듈 | 위치 | 핵심 기능 |
|------|------|----------|
| **LevelEditor** | Editor/ | 메인 에디터 프레임, 뷰포트 탭(최대 5개), 씬 아웃라이너, 탭 도킹 |
| **ViewportInteraction** | Editor/ | 기즈모 기반 액터 트랜스폼(이동/회전/스케일), 마우스 드래그 조작 |
| **ViewportSnapping** | Editor/ | 그리드/꼭짓점/면 스냅 |
| **SceneOutliner** | Editor/ | 씬 계층 트리뷰 (액터/컴포넌트/폴더), 필터링, 드래그앤드롭 |
| **PlacementMode** | Editor/ | 액터 배치 브라우저 (카테고리별 분류, 드래그 배치) |
| **MergeActors** | Editor/ | 다수 액터를 하나로 병합 |
| **ComponentVisualizers** | Editor/ | 컴포넌트 시각화 (라이트 범위, 콜리전 등 기즈모) |
| **PixelInspector** | Editor/ | 뷰포트 픽셀 정보 검사 |

### B. 프로퍼티/디테일 편집 (Property Editing)

| 모듈 | 위치 | 핵심 기능 |

| **SettingsEditor** | Developer/ | 설정 편집 위젯 |

## 2. 카테고리별 UE4 핵심 기능 목록

### A. 뷰포트/씬 편집
- 3D 뷰포트 렌더링 (와이어프레임/리트/언리트 모드)
- 기즈모 기반 트랜스폼 (이동/회전/스케일)
- 그리드/꼭짓점/면 스냅
- 다중 뷰포트 (최대 5개, 직교/원근)
- 씬 아웃라이너 (계층 트리 + 검색/필터)
- 액터 배치 (카테고리별 배치 브라우저)
- 컴포넌트 시각화 기즈모
- PIE (Play In Editor)

### B. 프로퍼티 편집
- 리플렉션 기반 자동 프로퍼티 패널 생성
- 타입별 전용 위젯 (int→SpinBox, Color→ColorPicker, Vector→3축 입력)
- 클래스별/타입별 커스텀 레이아웃 등록
- 카테고리별 프로퍼티 그룹핑
- 프로퍼티 검색/필터
- Undo/Redo 트랜잭션 연동
- 멀티 오브젝트 동시 편집

### C. 에셋 관리
- 에셋 브라우저 (폴더 트리 + 3종 뷰 모드)
- 3단계 필터링 (Backend/Frontend/텍스트)
- 에셋 썸네일
- 에셋 드래그앤드롭
- 에셋 컬렉션(북마크)
- 에셋 타입별 에디터 자동 연결
- 에셋 임포트/익스포트
- 파생 데이터 캐시

### D. 노드 그래프
- 범용 노드 그래프 프레임워크 (노드/핀/연결)
- 줌/팬/선택 박스
- 노드 컨텍스트 메뉴 확장
- 블루프린트 비주얼 스크립팅
- 머티리얼 셰이더 그래프
- 그래프 디버깅 (실행 흐름 표시)
- 노드 검색/코멘트

### E. 타임라인/시퀀서
- 트랙 기반 타임라인 편집
- 키프레임 삽입/삭제/이동
- 커브 에디터 (보간 모드, 탄젠트)
- 트랜스폼/프로퍼티/이벤트 트랙
- 재생/스크러빙
- 시네마틱 카메라 편집

### F. 브러시/페인트
- 버텍스 컬러 페인팅
- 텍스처 페인팅
- 지형 스컬프팅 (올리기/내리기/평탄화/침식)
- 지형 웨이트맵 페인팅
- 폴리지 배치 (밀도/랜덤 회전/스케일)

### G. 프로파일링/디버깅
- 성능 프로파일러 (CPU/GPU 타이밍)
- 트레이스 기반 분석 (Insights)
- 인게임 디버그 오버레이
- 출력 로그
- 메시지 로그 (빌드/컴파일)
- 콜리전 분석

## 3. 우선순위 분류

### Tier 1: 필수 (에디터 없으면 개발 불가)

| 기능 | 이유 | 관련 UE4 모듈 |
|------|------|---------------|
| **3D 뷰포트** | 씬을 볼 수 없으면 에디터가 아님 | LevelEditor, ViewportInteraction |
| **기즈모 트랜스폼** | 오브젝트 배치/이동이 에디터의 핵심 | ViewportInteraction, ViewportSnapping |
| **프로퍼티 편집기** | 오브젝트 속성 조정이 필수 | PropertyEditor, DetailCustomizations |
| **씬 아웃라이너** | 씬 내 오브젝트 관리 (선택/검색/계층) | SceneOutliner |
| **에셋 브라우저** | 에셋 탐색/선택/로드 | ContentBrowser, AssetTools |
| **출력 로그** | 디버깅 기본 도구 | OutputLog |
| **Undo/Redo** | 실수 복구 필수 | UndoHistory (+ 엔진 트랜잭션) |
| **메인 메뉴/툴바** | 에디터 UI 뼈대 | MainFrame, ToolMenus |
| **설정 편집** | 프로젝트/에디터 설정 조정 | Settings, SettingsEditor |

### Tier 2: 핵심 편의 (생산성에 큰 영향)

| 기능 | 이유 | 관련 UE4 모듈 |
|------|------|---------------|
| **노드 그래프 에디터** | 비주얼 스크립팅/머티리얼 편집 | GraphEditor |
| **에셋별 전용 에디터** | 메시/텍스처/머티리얼 프리뷰/편집 | StaticMeshEditor, TextureEditor 등 |
| **타임라인/시퀀서** | 애니메이션/시네마틱 편집 | Sequencer, CurveEditor |
| **커브 에디터** | 키프레임 보간 편집 | CurveEditor |
| **배치 브라우저** | 빠른 액터 배치 | PlacementMode |
| **멀티 뷰포트** | 직교 뷰 등 다각도 확인 | LevelEditor |
| **프로퍼티 검색/필터** | 복잡한 오브젝트의 속성 빠른 접근 | PropertyEditor |
| **파일 감시** | 에셋 파일 변경 자동 감지 | DirectoryWatcher |
| **메시지 로그** | 빌드/컴파일 오류 표시 | MessageLog |
| **레이어** | 씬 정리 | Layers |

### Tier 3: 고급 (특정 워크플로우에 필요)

| 기능 | 이유 | 관련 UE4 모듈 |
|------|------|---------------|
| **지형 에디터** | 오픈월드 전용 | LandscapeEditor |
| **폴리지 도구** | 자연 환경 전용 | FoliageEdit |
| **메시 페인트** | 버텍스 컬러 전용 | MeshPaint |
| **피직스 에셋 에디터** | 래그돌 설정 전용 | PhysicsAssetEditor |
| **애니메이션 에디터** | 애님 전용 (FMOD로 사운드 관리 시 별도) | AnimationEditor, AnimGraph |
| **프로파일러** | 최적화 단계에서 필요 | Profiler, TraceInsights |
| **인게임 디버거** | 게임플레이 디버깅 전용 | GameplayDebugger |
| **위젯 디자이너** | 인게임 UI 전용 | UMGEditor |
| **월드 구성** | 서브레벨/스트리밍 전용 | WorldBrowser |

## 4. ImGui로 구현할 때의 접근 방식

### Tier 1 기능 — ImGui 구현 접근법

#### 4.1 뷰포트 + 기즈모

```
ImGui::Begin("Viewport");
ImVec2 size = ImGui::GetContentRegionAvail();
// DX11 렌더타겟에 씬 렌더링 → ImGui::Image()로 표시
ImGui::Image(sceneRTV_SRV, size);
// ImGuizmo 라이브러리로 기즈모 오버레이
ImGuizmo::Manipulate(view, proj, op, mode, matrix);
ImGui::End();
```

- **씬 렌더링**: 별도 RenderTarget에 씬을 렌더링하고, SRV를 `ImGui::Image()`로 표시
- **기즈모**: [ImGuizmo](https://github.com/CedricGuillemet/ImGuizmo) 라이브러리 활용
  - 이동/회전/스케일 기즈모 내장
  - 로컬/월드 좌표계 전환 지원
- **스냅**: ImGuizmo의 snap 파라미터로 그리드 스냅 구현
- **멀티 뷰포트**: ImGui 도킹으로 다중 뷰포트 탭

#### 4.2 프로퍼티 편집기

```
// 리플렉션 메타데이터 기반 자동 생성
for (auto& prop : object->GetReflection()->GetProperties()) {
    DrawProperty(prop);  // 타입별 위젯 분기
}
```

- **핵심 설계**: 자체 리플렉션/메타데이터 시스템 → 타입별 위젯 매핑 테이블
- **타입별 위젯**:
  - `int/float` → `ImGui::DragInt/DragFloat`
  - `bool` → `ImGui::Checkbox`
  - `FVector` → `ImGui::DragFloat3`
  - `FColor` → `ImGui::ColorEdit4`
  - `enum` → `ImGui::Combo`
  - `std::string` → `ImGui::InputText`
- **커스텀 등록**: `std::unordered_map<TypeID, DrawFunction>` 테이블
- **카테고리**: `ImGui::CollapsingHeader()`로 그룹핑
- **Undo 연동**: 값 변경 전 스냅샷 → 커맨드 패턴
- **멀티 오브젝트**: 동일 프로퍼티 비교, 다르면 "Multiple Values" 표시

#### 4.3 씬 아웃라이너

```
// 재귀 트리 노드
void DrawOutliner(Entity entity) {
    bool open = ImGui::TreeNodeEx(name, flags);
    // 드래그앤드롭으로 부모 변경
    if (ImGui::BeginDragDropSource()) { ... }
    if (open) {
        for (auto& child : entity.Children())
            DrawOutliner(child);
        ImGui::TreePop();
    }
}
```

- **구조**: `ImGui::TreeNodeEx()` 기반 재귀 트리
- **검색**: `ImGui::InputText()` + 이름 필터링
- **드래그앤드롭**: `ImGui::BeginDragDropSource/Target()`
- **다중 선택**: Ctrl/Shift 클릭 지원

#### 4.4 에셋 브라우저

- **폴더 트리**: `ImGui::TreeNode()`로 디렉터리 구조
- **에셋 그리드**: `ImGui::ImageButton()`으로 썸네일 타일
- **뷰 모드 전환**: 리스트/타일 토글
- **필터링**: 텍스트 검색 + 타입 필터 콤보박스
- **더블클릭**: 에셋 타입에 따른 전용 에디터 열기

#### 4.5 출력 로그

```
ImGui::Begin("Output Log");
ImGui::InputText("Filter", filterBuf, ...);
for (auto& msg : logMessages) {
    if (PassesFilter(msg)) {
        ImGui::TextColored(GetColor(msg.level), msg.text);
    }
}
ImGui::End();
```

- **스크롤**: `ImGui::SetScrollHereY(1.0f)`로 자동 하단 스크롤
- **로그 레벨별 색상**: Error=빨강, Warning=노랑, Info=흰색
- **필터**: 텍스트 + 로그레벨 필터

#### 4.6 메인 메뉴/툴바/도킹

- **메뉴**: `ImGui::BeginMainMenuBar()` + `BeginMenu()`
- **툴바**: `ImGui::ImageButton()`으로 아이콘 버튼 행
- **도킹**: ImGui 내장 Docking Branch의 `DockSpace` API
  - `ImGui::DockSpaceOverViewport()` — 전체 뷰포트 도킹
  - `ImGui::DockBuilderAddNode/SplitNode` — 초기 레이아웃 구성
- **레이아웃 저장/복원**: `ImGui::SaveIniSettingsToDisk/LoadIniSettingsFromDisk`

### Tier 2 기능 — ImGui 구현 접근법

#### 4.7 노드 그래프 에디터

- **imnodes** 또는 **imgui-node-editor** 라이브러리 활용
- 노드: 입력/출력 핀, 연결선, 줌/팬
- 커스텀 노드 타입 등록 → 팩토리 패턴
- 컨텍스트 메뉴: 우클릭 → 노드 생성 목록

#### 4.8 타임라인/커브 에디터

- **ImSequencer** 또는 자체 구현
- 트랙 목록 (좌측) + 타임라인 (우측) 분할
- 키프레임: 드래그 가능한 마커
- **커브**: `ImGui::PlotLines()` 커스텀 또는 전용 커브 위젯
- 스크러빙: 타임라인 헤더 드래그

#### 4.9 에셋별 전용 에디터

- 프리뷰 뷰포트: 별도 RenderTarget + ImGui::Image
- 에셋 타입별 도킹 탭 자동 구성
- 머티리얼 에디터: 노드 그래프 + 프리뷰 뷰포트 + 프로퍼티 패널

## 5. 프레임워크에서 에디터에 노출해야 하는 데이터

### 5.1 필수 노출 (Tier 1 기능 지원)

| 데이터 | 용도 | 노출 방식 |
|--------|------|----------|
| **씬 그래프 (엔티티/컴포넌트 계층)** | 아웃라이너, 뷰포트 | 트리 순회 API |
| **엔티티/컴포넌트 리플렉션** | 프로퍼티 에디터 | 메타데이터 시스템 (타입, 이름, 범위, 카테고리) |
| **트랜스폼** | 기즈모 조작 | Get/Set World/Local Transform |
| **선택 상태** | 아웃라이너/뷰포트/디테일 동기화 | SelectionManager (이벤트 포함) |
| **에셋 목록** | 에셋 브라우저 | 에셋 레지스트리/파일 시스템 API |
| **에셋 메타데이터** | 썸네일, 필터링 | 타입, 경로, 태그 |
| **로그 스트림** | 출력 로그 | 로그 콜백/큐 |
| **Undo/Redo 스택** | 편집 복구 | 커맨드 패턴 + 트랜잭션 API |
| **설정 데이터** | 설정 에디터 | 직렬화 가능한 설정 오브젝트 |

### 5.2 핵심 편의 노출 (Tier 2 기능 지원)

| 데이터 | 용도 | 노출 방식 |
|--------|------|----------|
| **그래프 데이터 (노드/핀/연결)** | 노드 에디터 | 그래프 모델 API |
| **애니메이션 클립/커브** | 타임라인/커브 에디터 | 클립 데이터 + 키프레임 접근 |
| **머티리얼 파라미터** | 머티리얼 에디터 | 파라미터 목록 + 프리뷰 렌더링 |
| **메시 정보** | 메시 뷰어 | 버텍스/인덱스 + 바운딩박스 |
| **텍스처 SRV** | 텍스처 뷰어 | DX11 ShaderResourceView |
| **레이어 목록** | 레이어 관리 | 레이어 이름 + 엔티티 소속 |
| **빌드/컴파일 결과** | 메시지 로그 | 메시지 큐 (레벨, 텍스트, 소스 위치) |

### 5.3 노출 설계 원칙

1. **읽기/쓰기 분리**: 에디터가 데이터를 읽을 때와 수정할 때 경로를 분리 (수정은 반드시 트랜잭션 경유)
2. **이벤트 기반 동기화**: 데이터 변경 시 델리게이트/콜백으로 UI 갱신 트리거 (폴링 방지)
3. **리플렉션 메타데이터**: 카테고리, 표시 이름, 범위(min/max), 툴팁, 편집 가능 여부
4. **에셋 타입 레지스트리**: 타입별 에디터/썸네일 생성 함수 등록 테이블
