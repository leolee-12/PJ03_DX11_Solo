## 1. UCLASS/UPROPERTY/UFUNCTION 매크로가 생성하는 코드

### 1.1 매크로 정의 (ObjectMacros.h)

**UPROPERTY, UFUNCTION, UENUM** — 소스 헤더에서는 **빈 매크로**:

```cpp
#define UPROPERTY(...)   // 빈 매크로 — UHT가 파싱용으로만 사용
#define UFUNCTION(...)   // 빈 매크로
#define UENUM(...)       // 빈 매크로
```

**UCLASS** — `BODY_MACRO_COMBINE`으로 _PROLOG 매크로 생성:

```cpp
#define UCLASS(...) BODY_MACRO_COMBINE(CURRENT_FILE_ID, _, __LINE__, _PROLOG)
```

**GENERATED_BODY** — 토큰 결합으로 UHT 생성 코드 참조:

```cpp
#define BODY_MACRO_COMBINE(A,B,C,D) A##B##C##D
#define GENERATED_BODY(...)        BODY_MACRO_COMBINE(CURRENT_FILE_ID,_,__LINE__,_GENERATED_BODY);
#define GENERATED_UCLASS_BODY(...) BODY_MACRO_COMBINE(CURRENT_FILE_ID,_,__LINE__,_GENERATED_BODY_LEGACY);
```

- `CURRENT_FILE_ID`: UHT가 소스 파일 경로 기반으로 생성하는 고유 상수
- `__LINE__`: 동일 파일 내 복수 GENERATED_BODY 구분
- 결과: `{FileID}_{Line}_GENERATED_BODY` → UHT가 .generated.h에 정의

### 1.2 DECLARE_CLASS — StaticClass() 등 핵심 정적 메서드 (ObjectMacros.h:1552)

```cpp
#define DECLARE_CLASS(TClass, TSuperClass, TStaticFlags, TStaticCastFlags, TPackage, TRequiredAPI) \
private: \
    TRequiredAPI static UClass* GetPrivateStaticClass(); \
public: \
    typedef TSuperClass Super; \
    typedef TClass ThisClass; \
    inline static UClass* StaticClass() { return GetPrivateStaticClass(); } \
    inline static const TCHAR* StaticPackage() { return TPackage; } \
    inline static EClassCastFlags StaticClassCastFlags() { return TStaticCastFlags; } \
    // + 커스텀 operator new (StaticAllocateObject 호출)
```

### 1.3 IMPLEMENT_CLASS — GetPrivateStaticClass() 구현 (ObjectMacros.h:1710)

```cpp
#define IMPLEMENT_CLASS(TClass, TClassCrc) \
    static TClassCompiledInDefer<TClass> AutoInitialize##TClass(...); \
    UClass* TClass::GetPrivateStaticClass() { \
        static UClass* PrivateStaticClass = NULL; \
        if (!PrivateStaticClass) { \
            GetPrivateStaticClassBody( \
                StaticPackage(), TEXT(#TClass), PrivateStaticClass, \
                StaticRegisterNatives##TClass, sizeof(TClass), alignof(TClass), \
                (EClassFlags)TClass::StaticClassFlags, TClass::StaticClassCastFlags(), \
                TClass::StaticConfigName(), \
                (UClass::ClassConstructorType)InternalConstructor<TClass>, \
                /* VTableHelper, AddReferencedObjects, Super::StaticClass, WithinClass */ \
            ); \
        } \
        return PrivateStaticClass; \
    }
```

- `TClassCompiledInDefer<TClass>`: 전역 정적 초기화자 — 부트스트랩 큐에 등록
- `GetPrivateStaticClassBody()`: UClass 인스턴스 생성 + 메타데이터 설정
- Lazy 초기화 (첫 `StaticClass()` 호출 시)

## 2. UHT가 만드는 .generated.h 파일 구조

### 2.1 Z_Construct_UClass 패턴 (IMPLEMENT_INTRINSIC_CLASS, ObjectMacros.h:1740)

```cpp
UClass* Z_Construct_UClass_AMyActor() {
    static UClass* Class = nullptr;
    if (!Class) {
        Class = Z_Construct_UClass_AMyActor_Statics::Construct();
    }
    return Class;
}
```

### 2.2 Statics::Construct() 내부 흐름

```
Z_Construct_UClass_AMyActor_Statics::Construct()
  ├─ Z_Construct_UClass_AActor()       ← 부모 클래스 먼저 등록
  ├─ UClass* Class = AMyActor::StaticClass()
  ├─ UObjectForceRegistration(Class)
  ├─ [프로퍼티 등록]
  │   ├─ new FIntProperty(Class, "Health", offsetof(AMyActor, Health), ...)
  │   └─ new FObjectProperty(Class, "Weapon", offsetof(AMyActor, Weapon), ...)
  ├─ [함수 등록]
  │   └─ StaticRegisterNatives_AMyActor()
  │        └─ FNativeFunctionRegistrar::RegisterFunction(Class, "Jump", &AMyActor::execJump)
  └─ Class->StaticLink()               ← 프로퍼티 오프셋 확정, PropertyLink 구축
```

### 2.3 FCompiledInDefer — 등록 큐

```cpp
static FCompiledInDefer Z_CompiledInDefer_UClass_AMyActor(
    Z_Construct_UClass_AMyActor,       // 등록 함수
    &AMyActor::StaticClass,            // StaticClass 획득 함수
    TEXT("/Script/MyGame"),             // 패키지명
    TEXT("AMyActor"),                   // 클래스명
    false                              // 동적 여부
);
```

### 2.4 클래스 등록 타임라인

```
프로그램 시작
  ├─ [1] 전역 정적 초기화자 실행
  │    └─ TClassCompiledInDefer<T> 생성자 → 등록 큐에 추가
  ├─ [2] ProcessNewlyLoadedUObjects() 호출
  │    └─ 큐의 각 클래스에 대해:
  │         ├─ Z_Construct_UClass_T() 호출
  │         │    ├─ GetPrivateStaticClassBody() → UClass 인스턴스 생성
  │         │    ├─ StaticRegisterNatives() → 네이티브 함수 등록
  │         │    ├─ 프로퍼티 FProperty 생성 + 오프셋 설정
  │         │    └─ StaticLink() → PropertyLink 체인 구축
  │         └─ CDO 생성 (GetDefaultObject)
  └─ [3] UObject 시스템 사용 준비 완료
```

## 3. 런타임 프로퍼티/함수 조회 흐름

### 3.1 프로퍼티 조회

**TFieldIterator** (`UnrealType.h`) — UStruct의 모든 필드 순회:

```cpp
for (TFieldIterator<FProperty> It(MyClass); It; ++It) {
    FProperty* Prop = *It;
    // Prop->GetFName(), Prop->GetOffset_ForInternal() 등
}
```

- `ChildProperties` (FField* 링크드 리스트) 순회
- `IncludeSuper` 옵션으로 기저 클래스 프로퍼티 자동 포함
- `IncludeDeprecated`, `IncludeInterface` 옵션

**FindPropertyByName** (`Class.cpp`) — 이름으로 직접 검색:

```cpp
FProperty* UStruct::FindPropertyByName(FName InName) const;
// PropertyLink 연결 리스트 순회, FName 비교
```

```cpp
UFunction* UClass::FindFunctionByName(FName InName, EIncludeSuperFlag::Type IncludeSuper) const {
    UFunction* Result = FuncMap.FindRef(InName);    // O(1) 해시맵 검색
    if (!Result && IncludeSuper) {
```

- `FuncMap`: 현재 클래스의 `TMap<FName, UFunction*>`

### 3.3 함수 호출 — ProcessEvent (`ScriptCore.cpp:1848`)

```
UObject::ProcessEvent(UFunction* Function, void* Parms)
  ├─ IsPendingKill 확인
  ├─ Native 함수: GetFunctionCallspace → Remote면 RPC 전송
  ├─ 스택 프레임 할당 (FMemory_Alloca 또는 PersistentFrame)
  ├─ 파라미터 복사: Memcpy(Frame, Parms, ParmsSize)
  ├─ FFrame 생성 (Object, Function, Frame, ChildProperties)
  ├─ Out 파라미터 → FOutParmRec 연결 리스트 구성
  ├─ 로컬 변수 InitializeValue_InContainer
  ├─ Function->Invoke(this, Stack, ReturnValueAddress)
  │    └─ (*Func)(Obj, Stack, RESULT_PARAM)  ← 함수 포인터 호출
  └─ 로컬 변수 정리 (DestroyValue_InContainer)
```

### 3.4 프로퍼티 값 읽기/쓰기

**ContainerPtrToValuePtr** — 오프셋 기반 주소 계산:

```cpp
// 핵심 계산식
실제주소 = (uint8*)ContainerPtr + Offset_Internal + ElementSize * ArrayIndex
```

**값 접근 API** (`UnrealType.h`):

| API | 설명 |
|-----|------|
| `ContainerPtrToValuePtr<T>(Obj)` | 오브젝트에서 프로퍼티 주소 계산 |
| `GetPropertyValue_InContainer(Obj)` | 값 읽기 (타입 안전) |
| `SetPropertyValue_InContainer(Obj, Value)` | 값 쓰기 |
| `CopyCompleteValue(Dest, Src)` | 완전 복사 (배열 포함) |
| `InitializeValue_InContainer(Obj)` | 기본값 초기화 |
| `DestroyValue_InContainer(Obj)` | 값 소멸 (비네이티브 타입) |

### 3.5 UStruct::Link() — PropertyLink 체인 구축 (`Class.cpp:766`)

```
UStruct::Link(Ar, bRelinkExistingProperties)
  ├─ 상위 클래스 Preload (크기/정렬 상속)
  ├─ PropertiesSize = SuperStruct->GetPropertiesSize()
  ├─ MinAlignment = SuperStruct->GetMinAlignment()
  ├─ ChildProperties 순회:
  │    ├─ Property->Link(Ar) — 오프셋 계산
  │    │    ├─ LinkInternal(Ar) — 타입별 초기화
  │    │    └─ SetupOffset() — Offset_Internal 확정
  │    └─ MinAlignment = Max(MinAlignment, Property->GetMinAlignment())
  └─ PropertyLink 연결 리스트 구축 (파생→기반 순)
```

**PropertyLink 체인 종류**:

| 체인 | 용도 |
|------|------|
| `PropertyLink` | 전체 프로퍼티 (파생→기반) |
| `RefLink` | UObject* 참조 프로퍼티만 (GC용) |
| `DestructorLink` | 소멸 필요 프로퍼티만 |
| `PostConstructLink` | 생성 후 초기화 필요 프로퍼티 |

## 4. 리플렉션 ↔ 에디터 디테일 패널 연결

### 4.1 전체 흐름

```
UPROPERTY 정의 (PropertyFlags + MetaDataMap)
  ↓
TFieldIterator<FProperty> (상속 체인 순회)
  ↓
PropertyEditorHelpers::ShouldBeVisible() (가시성 판정)
  ├─ CPF_Edit 플래그 확인
  ├─ MetaData 확인 (EditInline, bShowOnlyWhenTrue)
  └─ Category 숨김 확인
  ↓
FObjectPropertyNode::GetCategoryProperties() (카테고리별 분류)
  └─ GetMetaData("Category") → 카테고리명 ('|'로 계층화)
  ↓
FDetailLayoutBuilderImpl (카테고리별 FDetailCategoryImpl 생성)
  ↓
SDetailsView (Slate 위젯 렌더링)
```

### 4.2 프로퍼티 메타데이터 저장소

**PropertyFlags** (컴파일 타임, 빠른 비트 연산):

| 플래그 | 의미 |
|--------|------|
| `CPF_Edit` | EditAnywhere/EditDefaultsOnly |
| `CPF_DisableEditOnInstance` | EditDefaultsOnly (인스턴스 편집 불가) |
| `CPF_AdvancedDisplay` | 고급 표시 (접힌 상태) |
| `CPF_EditConst` | VisibleAnywhere (읽기 전용) |

**MetaDataMap** (런타임, `TMap<FName, FString>`, 에디터 전용):

| 키 | 용도 |
|----|------|
| `Category` | 디테일 패널 카테고리 분류 |
| `DisplayName` | 표시 이름 |
| `EditInline` | 인라인 편집 |
| `ShowOnlyInnerProperties` | 내부 프로퍼티만 표시 |
| `bShowOnlyWhenTrue` | 조건부 표시 |
| `ToolTip` | 툴팁 텍스트 |

### 4.3 메타데이터 조회 API (FField, `Field.h`)

```cpp
bool  HasMetaData(FName Key) const;
const FString& GetMetaData(FName Key) const;
bool  GetBoolMetaData(FName Key) const;
int32 GetIntMetaData(FName Key) const;
void  SetMetaData(FName Key, const TCHAR* Value);
```

- `WITH_EDITORONLY_DATA` 블록 내 — 에디터 빌드에서만 존재
- `MetaDataMap`: `TMap<FName, FString>` (FField 멤버)
